## 为什么归档而不是删除

这三份记录了"为什么当初那样改"：参数为什么判定为死参数、
skill 为什么从 vendor 迁出来、上游 `h3_generator.py` 的哪些 `False`
是等价化简而不是 bug。删掉会让这些问题被重复讨论一遍。

但它们**不能**留在 `docs/` 顶层：那里放的是"现在是什么样"，
混入过时结论正是这个项目历史上"文档说一套、代码做另一套"的来源之一。
