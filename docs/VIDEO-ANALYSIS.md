## 叙事解读

**这是一个"告白/和解"的收束段落。**

两个曾经关系破裂的人（MyGO!!!!! 剧情背景），在黄昏的海边并肩走、坐下、然后其中一个人（祥子）伸手碰了另一个人的腿和脸。被触碰的人（睦子）笑了。

**情绪曲线**：平静（镜头 1-2）→ 靠近（镜头 3-4）→ 触碰（镜头 5A）→ 回应（镜头 5B）

**关键手法**：
1. **不拍全身拍手** —— 镜头 5A 用大特写代替拥抱，更有张力
2. **光比递进** —— 4:1 → 5:1 → 6:1，越近越暗，情绪越深
3. **手先于脸** —— 先给手，再给脸，制造等待
4. **结尾不切走** —— 停在脸上，让情绪落地

## 我的复刻方案

**5 段续写，每段约 5 秒，总约 25 秒**

| 段 | 内容 | 光比 | 机位 |
|---|---|---|---|
| 1 | 大全景，两人并肩走向海，背对镜头 | 4:1 | static |
| 2 | 中近景侧脸，两人看海 | 5:1（接近 4:1） | static |
| 3 | 中景，睦子坐下，祥子站立 | 4:1 | static |
| 4 | 中景，两人并坐 | 4:1 | static |
| 5 | 手部特写 → 脸部特写 | 6:1 | slow push |

用**潜空间续写**串成一条连续镜头（段 2 起承接 latent），
保证动作、光线、服装全部连续。
