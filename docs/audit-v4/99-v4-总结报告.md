## 一、软件是什么

四层运行时，**三条互不相干的数据链**：

```
① DSH Host（Node ESM, host/）
     host/index.js        apply()：注册路由 / 14 个工具 / skill provider / 启动编排
     host/api/            REST 分发器（拆成 11 个域 router）
     host/bridge/         ★ 唯一知道「上游 ComfyUI 节点长什么样」的层
     host/services/       业务服务（37 文件）
     host/store/          模型与原子持久化
② Web SPA（React 18 + TS, app-src/src/）→ 构建到 app-dist/
③ ComfyUI 0.45.0 + vendor/nanfeng（221 参数巨型节点）+ vendor/inpaint-nodes（局部重绘）
④ Blender 5.2.4 灰模预演（子进程）+ ffmpeg 后处理/剪辑
```

| 链 | 入口 | 关键路径 |
|---|---|---|
| **A 单镜生成** | `POST /generate` / `studio_generate` | shot-context → ref-images → h3-prompt 编译 → accel-plan → nanfeng buildShotWorkflow → comfy-client |
| **B 续写批次** | `POST /nanfeng/continuation/batches/run` | continuation.runBatch → 串行 job → latent 落盘 → 段 n+1 |
| **C 图像** | `POST /image/generate` / `POST /image/inpaint` | h3-image / h3-inpaint → comfy-client → 归档 |

三条链共用 `comfy-client` / `job-runner` / `job-store` / `ref-images` / `asset-service`。

### 2.2 P1（功能失效 / 违反契约）—— 摘要

- **续写链路**：批次选了 `contextLength=56` 实际按 22 跑；`runBatch` 无租约/CAS，
  崩溃后永久卡 `running`；段超时 1h 与 comfy 的 2h 冲突，长片必然误判。
- **任务系统**：`queued` 僵尸任务永不执行；启动恢复不清远端，产物成孤儿；
  取消与完成竞态会把已下载产物丢掉。
- **图像**：inpaint 链路不走 `solveImageLoraStack`（画风默认 0.8 失效、
  ±5 滑块被静默夹到 ±2）；`meta` 回报基准常量而非实际生效值；
  `GrowMask` 的 expand 随分辨率缩放，448² 档只剩 7px（不足 1 latent 格）。
- **前端**：`ImagePage` 切 tab 卸载 `InpaintPanel`，源图/mask/进行中的任务全丢。
- **双入口漂移**：`qc` 入参形状、`studio_edit` 丢 `reencode`、`studio_blender` 丢
  `timeoutMs`、`backends` 同名不同型、Agent 出图不归档、Agent 生成丢 lint 警告。
- **错误映射**：`CODE_STATUS` 只登 32/80，**66 个错误码落 500**。
- **并发**：续写批次无 in-flight 锁，双 POST 可双跑；`character-vault`/`canvas-agent`
  的 tmp 名含 pid，同进程并发写必冲突；`edit.js` 裸 `writeFileSync` 无原子保护。
- **边界**：`tools.js` 五处深路径绕开 `bridge/index.js` 门面；
  `prompt-normalizer` 反向依赖 `services/prompt-llm.js`；
  而当时的边界守卫**只扫 services/api，不扫 tools.js**，所以长期绿灯。

### 2.3 结构性问题（"管线混在一起"的证据）

## 七、需要重启 DSH 才能生效

本次改动涉及 `host/index.js`（静态挂载）、`host/security.js`、`host/tools.js`、
`host/api/**`、`host/bridge/**`、`host/services/**` 与 `app-dist/**`。
按仓库约定（**改 `inject` 后必须重启 DSH，HMR 不会重新解析**），以及 `app-dist` 是全量重建，
需要**重启 DSH 一次**才能让新路由与新构建产物生效。
