## 0. 已冻结的四条决策

| # | 决策 | 理由 |
|---|---|---|
| 1 | **顺序：止血 → 画布闭环 → 功能域 → 大型模块** | 先让已有功能真正能用，再补新功能 |
| 2 | **图片引用池 `__img_ref__` 是画布闭环的前置** | 不做它，画布一写 base64 项目文件就膨胀百倍 |
| 3 | **漫画工作台与画布闭环并行推进** | 漫画 7/15 站是本地零费用渲染，不依赖模型即可产出 PDF/CBZ，见效快 |
| 4 | **明确不复刻 8 个域** | `auth` `license` `update` `activate` `splash` `login` `gallery` `jimeng`（DSH 宿主已有或本地自用无需求） |

## 2. 技术约束（不可违反）

| 约束 | 说明 |
|---|---|
| **H3 分辨率** | 必须 32 倍数且在官方档位（864×480/960×544/1056×608/1344×768），否则 RuntimeError |
| **H3 cfg** | 必须 1.0（CFG 蒸馏模型） |
| **H3 length** | 必须 17k+5 网格（124/244/362） |
| **H3 音频 VAE** | 必须 fp32，fp16 会静音 |
| **参考图上限** | Ref2VA 的 `ref_images` 最多 9 张 |
| **Seedance 无 key** | 走 Mock，但请求体结构必须真实（分辨率/时长/画幅都要传） |
| **API 前缀** | 全部 `/luoshu/*`，绝不碰 DSH 的 `/api` |
| **鉴权** | 所有写操作必须校验 `X-JZ-Token` + Origin 同源 |
| **可执行路径** | 不接受来自配置/接口的注入 |
| **存储** | 画布写盘前必须过 `__img_ref__` 引用池 |
