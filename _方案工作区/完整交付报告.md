## 五、H3 提示词体系（用户模板资产）

按用户提供的 7 份模板文件实现：

**9 种画风**（英文原文 + 中文禁止词）
地狱把妹王（外观版/画风版）· 90年代OVA · 新海诚 · 吉卜力 ·
经典美式卡通 · 飞碟社 · 三渲二+PBR · GoHands

**5 种模式**
T2VA · I2VA · FL2VA · L2VA · Ref2VA

**六段式结构**（Ref2VA）
```
CRITICAL STYLE RULE（英文画风 + 中文禁止词）
CRITICAL REFERENCE RULE（图/视频/音频用途声明）
subject_definitions（外观一次绑定）
CHARACTER DEFINITION（性别/身高/特征/性格/音色）
summary → retention_analysis
non_diegetic_music → SCENE LAYOUT
overall_soundscape → MOTION DESCRIPTION
```

**关键规则已代码化**
- 画风必须英文，其余中文
- 音色只在 CHARACTER DEFINITION 绑定一次，分镜只写 `(S1)` + 情绪
- 三个声音字段不能空
- 参考视频必须声明用途（motion/rhythm/mood/continuation）
- H3 硬约束校验（9 图 / 3 视频 / 3 音频 / 12 总数 / 4-15 秒 / 7000 字符）
