# 人物替换专属规范 v1.0

> 核心场景：视频换人、角色替换（Video Editing）。
>
> 底层逻辑：H3 注意力极度有限。替换任务的核心是「**保动作、换皮囊**」。
> 必须把最强的注意力放在「身份映射」和「动作复刻」上，
> 绝不能让它分心去重绘背景或生成音频。

---

## 一、四大铁律（严禁混入六字段规范）

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | **禁用 `<Audio N>` 标签** | 纯视觉任务写音频标签，会诱导模型幻觉出音轨或嘴型 |
| 2 | **禁用 `overall_soundscape` / `non_diegetic_music` 字段** | 直接省略，防止注意力被音效描述分散 |
| 3 | **禁用长篇光影/环境描述** | 光影、构图、场景必须 100% 继承 `<Video 1>`；用文字重写会导致背景闪烁重绘 |
| 4 | **禁用 `Forbidden` 列表** | 把防御性约束融入正面描述中 |

> 这四条与 `jiuzhang-prompt-spec` 的常规六字段规范是**互斥**的：
> 常规规范要求六个字段齐全（含两个声音字段），替换任务要求**只有前三段**。
> 同一份提示词不能同时满足两者 —— 判定依据是任务类型，不是格式偏好。

---

## 二、标准四段式模板（直接复制填空）

```text
第一句（总结全片·最强注意力）：
将参考视频1视频中的[原角色A特征]替换成参考图1[目标角色B特征]。完全复刻参考视频1内动作。

第二句（锁定身份·建立映射）：
<Subject 1> 是 <Picture 1> 中的[目标角色B]，替换原视频中的[原角色A]。
<Video 1> 是源视频，保留其完整动作、运镜和剪辑节奏。

第三句（详细分镜·按时间轴拆解动作）：
[Shot 1] 起始帧：[景别]。[Subject 1] [动作描述]...
[Shot 2] At 00:02.500，[景别]。[Subject 1] [动作描述]...

第四句（强化约束·防漂移）：
全程保持 <Subject 1> 的身份和外观与 <Picture 1> 完全一致。完全复刻 <Video 1> 内动作，不添加新角色。
```

**四句的分工**：

| 句 | 作用 | 为什么这个位置 |
|---|---|---|
| 第 1 句 | 全片最高优先级指令 | 放最前面，权重最高；同时给出「原角色特征」和「目标角色特征」，建立映射关系 |
| 第 2 句 | 建立 `<Subject N>` / `<Video N>` 绑定 | 官方要求引用标签在使用前先定义一次 |
| 第 3 句 | 时间轴动作拆解 | 让模型知道每一秒该复刻什么，而不是自由发挥 |
| 第 4 句 | 防漂移 | 结尾再压一次身份一致性，抵消长提示词中的注意力衰减 |

## 三、实战示例：把源视频人物替换为「睦子」

背景：源视频 `<Video 1>` 是一段 5 秒的女性在走廊回头奔跑的镜头。
目标：把源视频里的金发女人，替换成「睦子」（`<Picture 1>`）。

```text
将参考视频1视频中的金发女人替换成参考图1中的睦子（浅绿长发、左侧发卡、琥珀瞳）。完全复刻参考视频1内动作。

<Subject 1> 是 <Picture 1> 中的睦子，替换原视频中的金发女人。
<Video 1> 是源视频，保留其完整动作、运镜和剪辑节奏。

[Shot 1] 起始帧：中景。原金发女人（现替换为 <Subject 1>）站在走廊尽头，身体背对镜头，随后突然转头，露出她的侧脸。
[Shot 2] At 00:02.000，特写。<Subject 1> 的面部正面朝向镜头，她快速眨眼，发丝随着转头动作甩动，左侧发卡清晰可见。
[Shot 3] At 00:03.500，中景。<Subject 1> 转身向画面右侧奔跑，镜头跟随她平移，衣摆随奔跑动作自然飘动。

全程保持 <Subject 1> 的身份和外观与 <Picture 1> 完全一致。完全复刻 <Video 1> 内动作，不添加新角色。
```

## 四、自查清单

- ☐ 第一句话是否同时包含了「原角色特征」和「目标角色特征」？
- ☐ 是否只使用了 `<Subject 1>` 和 `<Video 1>` 两个核心素材标签？
- ☐ 是否彻底删除了所有 `<Audio N>` 和音效字段？
- ☐ 分镜描述中，是否每一段都在强调「复刻原动作 / 原运镜」？

## 五、在本插件里怎么落地

### 5.1 提交参数

| 项 | 值 | 说明 |
|---|---|---|
| 模式 | `ref2va` | 替换任务必须有参考视频，走多参模式 |
| 图片槽 | `图片1` = 目标角色 | 对应 `<Picture 1>` |
| 视频槽 | `视频1` = 源视频 | 对应 `<Video 1>` |
| 音频槽 | **全部留空** | 铁律 1：不放 `<Audio N>` |
| 提示词 | 上面四段式全文 | 直接粘进 `提示词` 字段 |

### 5.2 与续写的关系

替换任务**通常不需要续写**（源视频本身就是连续的动作）。
如果源视频很长需要分段替换，每段必须用**同一个目标角色参考图**，
否则不同段的角色会漂成两个人。

### 5.3 与光影参数的关系

替换任务的 `lightingId` 应当设为 `none`（跟随源视频）。
手动指定光比会与铁律 3 冲突 —— 光必须 100% 继承源视频，
用文字重写会导致背景闪烁重绘。

### 5.4 常见失败与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 背景闪烁 / 重绘 | 提示词里写了光影或场景描述 | 删掉所有光影/环境句，只留动作 |
| 出现字幕或 UI | 没加 `Text suppression` 行 | 在分镜前补一行压制行（见 `jiuzhang-prompt-spec` §7.5 的三处合法位置） |
| 角色身份漂移 | 第 4 句缺失或太靠后 | 第 1 句和第 4 句都要带目标角色特征 |
| 生成了音轨/嘴型 | 写了 `<Audio N>` 或声音字段 | 铁律 1、2：全部删除 |
| 动作没复刻 | 分镜里没写「复刻原动作」 | 每个 `[Shot N]` 都加一句复刻声明 |
