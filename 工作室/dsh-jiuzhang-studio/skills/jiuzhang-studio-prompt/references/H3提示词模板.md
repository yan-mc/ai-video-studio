# H3 提示词模板（可复制）

> 对应《AI视频制作软件与H3本地部署深度指南》2.3 与附录 B。使用前替换 `[...]` 内容，保持字段名/顺序不变。

## 模板 1：T2VA 文生音视频（三段式）

```text
integrated_multimodal_description: [Shot 1] [风格/介质/光线/色调]，[景别] frames [主体]，[主体外观与动作]。The camera [运镜类型+幅度+速度] toward [目标]。At 00:0X.XXX, [切镜/事件]。[角色] (S1) says: <d>[Chinese] [台词]</d>。

overall_soundscape: [1—4 句：环境声/物理动作声/非语言人声；不重复台词与画内音乐]

non_diegetic_music: [1—3 句：乐器/速度/节奏/动态；无则写 N/A]
```

## 模板 2：I2VA / FL2VA / L2VA（关键帧 + 对齐指令）

```text
# FL2VA
How the reference pictures align with the target video — Picture 1 (from [Shot 1]) aligns with the 0.00-second mark of the target video; Picture 2 (from [Shot 1]) aligns with the [S.SS]-second mark of the target video.

integrated_multimodal_description: [Shot 1] [首帧状态] → [可观察的中间变化] → [逐步缩小差异] → [尾帧状态]。The camera [运镜]。[角色] (S1) says: <d>[Chinese] [台词]</d>。

overall_soundscape: [环境声/动作声]

non_diegetic_music: N/A
```

- I2VA 只写 Picture 1 对齐 0.00 秒；L2VA 只写 Picture 1 对齐结尾实际时长；
- `S.SS` 必须是后端实际有效时长（按 17k+5 帧网格换算，保留两位小数）。

## 模板 3：Ref2VA 参考生成（六段式）

```text
subject_definitions:
<Subject 1> is the [人物/物体] in <Picture 1>; preserve [脸部身份/发型/服装/配饰].
<Subject 2> is the [动作/表情/姿势] shown by <Video 1>.
<Video 1> provides the [运镜/节奏/时间结构] reference.
<Audio 1> is the [音色/台词/演唱] reference for <Subject 1> (S1).

summary:
[reference generation] Generate [任务一句话]，preserving <Subject 1>, transferring <Subject 2>'s [动作], following <Video 1>'s [运镜/节奏], using <Audio 1> as [音色] reference.

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - preserve [身份特征逐字].
<Subject 2> ([Shot 1] movement): attribute_transfer - transfer [动作/节奏].
<Video 1> (camera and pacing): weak_reference - follow [大致运镜方向/节拍] without copying frames.
<Audio 1>: reference - follow [音色/语气] without copying the waveform.

detailed_description:
[风格/介质/光线/色调总述]。[Shot 1] [景别+主体+空间关系+动作+运镜+光线]。[角色] (S1) says: <d>[Chinese] [原话]</d>。[Shot 2] At 00:0X.XXX, [切镜理由与新信息]。[动作/反应/声音]。[结尾落幅]。

overall_soundscape:
[1—4 句环境声/动作声/非语言人声]

non_diegetic_music:
[1—3 句配乐；无则 N/A]
```

## 写法检查清单

- [ ] 正文英文；台词/歌词/画面文字保留原语言；
- [ ] `[Shot 1]` 不加时间戳；后续镜头 `At MM:SS.mmm` 严格递增；
- [ ] 每个 `<Subject N>`/`<Video N>`/`<Audio N>` 都有 `retention_analysis` 一行；
- [ ] 台词放 `<d>[Chinese] ...</d>`；画外音说明嘴唇闭合；跨切镜用 `<scenetrans>`、截断用 `<cutoff>`；
- [ ] 无负向提示词（"不要 X"改写成正向约束或场景状态）；
- [ ] 全文 ≤7,000 字符（2K 再生成接口 ≤40,000，且必须是最终提示词）；
- [ ] 存档 `prompt_final.txt` 与素材哈希（2K 再生成必须原样回放）。
