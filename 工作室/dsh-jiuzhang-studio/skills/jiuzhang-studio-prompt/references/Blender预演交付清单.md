# Blender 预演 → AI 视频：镜头级交付清单

> 对应《AI视频制作软件与H3本地部署深度指南》第 3 章与附录 C。目标：让 Blender 预演真正变成模型能吃的"控制信号"，而不是一张参考图。

## 一、预演前

- [ ] 确认本镜头目标模型：H3 本地（ComfyUI + Fun ControlNet）/ H3 API（首尾帧或 Ref2VA）/ Wan 2.2 VACE / Seedance 2.5 白模 / 其他；
- [ ] 确认目标规格：时长 4—15s、分辨率（H3 768p → 1344×768 或 768×1344）、画幅比例；
- [ ] 角色/场景/道具使用**纯灰白模**（避免贴图被模型当平面图，出现穿模/脖子翻转）；
- [ ] 机位、景别、遮挡关系、动作节奏按最终分镜摆好；24fps。

## 二、需要导出的文件

| 文件 | 规格 | 用途 |
|---|---|---|
| `frame_first.png` | 目标画幅（如 1344×768），干净渲染 | H3 FL2VA/I2VA 首帧 / 参考图 |
| `frame_last.png` | 同上，留安全边 | H3 FL2VA 尾帧 |
| `depth.mp4` | 24fps、≤15s、与目标时长一致、灰度深度 | H3 Fun ControlNet Depth / Wan VACE |
| `pose.mp4` | 24fps、≤15s、骨架 | H3 Fun ControlNet Pose / Wan VACE |
| `canny.mp4` / `mlsd.mp4` | 24fps、≤15s | 硬边/建筑结构控制 |
| `camera.json` | 机位/焦距/关键帧/时间 | 软件记录 + 转写运镜提示词 |
| `motion_ref.mp4` | 2—15s、24fps、动作清晰 | H3 Ref2VA `<Video N>` 动作/运镜参考 |
| `char_*.png` | 2—4 张独立高清图（短边 2048），正/四分之三/侧/服装细节 | H3 Ref2VA `<Picture N>`；**不要 3×3 网格** |
| `scene_*.png` | 与分镜一致的场景参考 | 场景/风格参考 |
| `voice_*.wav` | 2—15s、32kHz、单一声源 | H3 `<Audio N>` 音色/台词参考 |

## 三、检查（上传前）

- [ ] 首帧已按目标画幅裁剪（H3 的 `first_frame` 直接缩放、不保比例，off-aspect 会拉伸；`last_frame` 会居中裁剪）；
- [ ] 控制视频帧率 24fps、时长与目标一致；不足补最后一帧、超出截断（H3 ComfyUI 行为）；
- [ ] 素材数量：H3 Ref2VA 图 ≤9、视频 ≤3、音频 ≤3、合计 ≤12；每段视频/音频 2—15s、各自总时长 ≤15s；
- [ ] 参考音频不是唯一参考（H3 要求至少 1 图或 1 视频）；
- [ ] 模式唯一：首尾帧模式与 Ref2VA 模式不混用；
- [ ] 提示词按官方结构（三段式/六段式）编译，标签与素材一一对应；
- [ ] 记录：Blender 版本、场景文件、机位、渲染参数、模型文件、LoRA、步数、flow_shift、seed、有效时长。

## 四、生成后 QC

- [ ] 首帧/尾帧与预演一致性（构图、景别、主体位置）；
- [ ] 深度/姿态与预演偏差（抽帧对比，记录偏差程度）；
- [ ] 角色身份/服装/道具一致性（对照角色卡）；
- [ ] 口型/对白/音效同步；
- [ ] 物理合理性（手部、穿模、反射、重力）；
- [ ] 画面文字/品牌字（H3 弱项，必要时后期贴图）；
- [ ] 通过/返修/重抽结论写入 `qc_report.json`，保留 take 编号与参数。

## 五、常见返修策略

| 问题 | 处理 |
|---|---|
| 构图/机位偏离预演 | 加大 ControlNet 强度（1.0 起调，过强会僵）；检查首帧是否正确裁切 |
| 角色漂移 | 改用 Ref2VA + 2—4 张独立角色图；缩短单镜时长；关键镜头用同角色 LoRA |
| 动作不对 | 用 pose/depth 控制视频；把动作拆成更短镜头；用 `MiniMaxH3AddGuide` 锚定关键帧 |
| 口型/台词不齐 | 台词写进 `<d>`；用音频参考 + 至少一张图；必要时后期对口型（LatentSync/EchoMimic） |
| 手部/物理崩 | 换 take；局部重绘（latent mask / retake）；避免复杂手部动作 |
| 分辨率不够 | SeedVR2/FlashVSR/视频增强软件超分；交付级 2K 走官方 Regenerate-2K |
| 画面文字糊 | 不让模型生成文字，后期贴图/字幕 |
