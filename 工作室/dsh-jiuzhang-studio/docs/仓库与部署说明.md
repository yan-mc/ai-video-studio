# 仓库与部署说明

## 两个仓库的关系

本工作区（`F:\AI视频`）的 git 仓库和 GitHub 上的 `yan-mc/ai-video-studio` **结构不同**，这是有意设计：

| | 本地工作区 | GitHub 远程 |
|---|---|---|
| 仓库根 | `F:\AI视频`（整个工作区） | 插件根目录 |
| 插件位置 | `工作室/dsh-jiuzhang-studio/` | 仓库根 |
| 用途 | 开发（含文档、运行时、其他服务） | 分发（可 clone 即用） |
| 文件数 | 32 个提交，仅跟踪插件目录 | 163 个文件，插件完整快照 |

**为什么这样**：本地工作区还有 `ai-runtime`（92GB 模型）、`studio-apps`、闭源拆解产物等，
不能入库；而分发时用户需要的是「clone 下来就是插件根」。

## 如何从本地同步到 GitHub

本地 `.gitignore` 只跟踪插件目录，所以可以整体提交到本地。
推到 GitHub 时需要用「插件根结构」重建：

```powershell
cd F:\AI视频
# 1) 建临时 worktree
$tmp = 'F:\AI视频\_gitbuild'
git worktree add --detach $tmp HEAD

# 2) 把插件内容拍平到根
cd $tmp
git checkout --orphan release-v1
# （手动或脚本：把 工作室/dsh-jiuzhang-studio/* 移到根）

# 3) 提交并推送
git add -A
git commit -m "..."
git push origin release-v1:main --force

# 4) 清理
cd F:\AI视频
git worktree remove $tmp --force
```

## 分发时的注意事项

### 必需的运行时（不入库）

| 依赖 | 说明 | 获取方式 |
|---|---|---|
| ComfyUI + 模型 | 约 60GB，H3 视频 + H3-Image | 见 `skills/jiuzhang-studio-setup` |
| ffmpeg | 314MB，合成/抽帧/探测都要用 | 见下 |
| Node 依赖 | `app-src/node_modules` | `npm i` in `app-src/` |

### ffmpeg 路径

单独 clone 时不会有内置 `tools/ffmpeg`。按优先级解析：

1. 环境变量 `DSH_FFMPEG_DIR` 或 `FFMPEG_DIR`
2. 插件配置 `ffmpegDir`
3. 插件自身位置向上找 `tools/ffmpeg`
4. PATH

```powershell
# 例
$env:DSH_FFMPEG_DIR = 'C:\ffmpeg'
```

### 构建前端

```powershell
cd app-src
npm install
npx vite build        # 产物落到 ../app-dist
```

`app-dist` 已入库，所以**不构建也能直接用**；改了 `app-src` 才需要重跑。

## 数据存放（不入库）

`data/` 下按用途分目录，`.gitignore` 已全部排除：

| 目录 | 内容 | 可否删除 |
|---|---|---|

| `previz/` | 白模视频与帧 | 可 |

| `inputs/` | ComfyUI staging 缓存 | 可（自动重建） |
| `vault/` | 角色卡定义 | 否 |
| `workflows/` | ComfyUI 工作流模板 | **必须保留**（已入库） |
| `config.json` | 插件配置 | 视情况 |
| `jobs.json` | 任务历史 | 可 |
