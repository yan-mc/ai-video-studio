# 九章工作室 · 使用指南

> 版本：1.0.0 · 更新：2026-11-12
> 界面入口：`http://127.0.0.1:<你的DSH端口>/luoshu/app/`

---

## 一、界面总览

打开后你会看到三部分：

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：品牌名 + 后端状态灯 + 强调色 + 主题切换 + 语言   │
├────────┬─────────────────────────────────────────────┤
│        │                                             │
│ 左侧   │            主内容区                          │
│ 导航   │       （每个页面的具体功能）                  │
│ 15 项  │                                             │
│        │                                             │
├────────┴─────────────────────────────────────────────┤
│ 底栏：当前项目名                                        │
└──────────────────────────────────────────────────────┘
```

### 顶栏三个状态灯

| 灯 | 含义 | 不亮怎么办 |
|---|---|---|
| **H3** | 本地 ComfyUI 是否连通 | 启动 ComfyUI（见部署 skill） |
| **Seedance Mock** | 云端后端状态；显示 Mock 表示无 API key | 在「设置」填 Seedance key 或保持 Mock |
| **预演引擎** | 3D 导演台后端是否连通 | 打开「预演」页点「启动引擎」 |

它们每 5 秒自动刷新，不用手动点。

### 顶栏右侧

- **强调色**：四个圆点，切换按钮/选中态的主色（朱砂红 / 靛蓝 / 金 / 松绿）
- **主题**：月亮/太阳图标，在「墨夜」（深色）与「宣纸」（浅色）间切换
- **语言**：中 / EN

### 1. 画布 `#/canvas`

**作用**：节点式工作流编排。整个插件的"主工作台"。

画布是无限大的，可以放各种节点、连线，数据从上游流向下游。

#### 顶部工具条

| 元素 | 作用 |
|---|---|
| **新建节点** | 打开分类菜单，8 个分组：文本 / AI 提取 / 图片 / 智能体 / 音频 / 视频 / 导演台 / 全景 |
| **撤销 / 重做** | 支持 12 步 |
| **缩放** | 缩小 / 百分比 / 放大 / 适应视图 |
| **锁定画布** | 锁定后节点不能拖动、不能连线，防误触 |
| **节点数 / 连线数** | 实时统计 |

#### 画布空白处右键

- 新建节点
- 粘贴（Ctrl+V 剪贴板内容）
- 全选
- 清空画布

#### 节点上右键

| 菜单项 | 作用 |
|---|---|
| **运行** | 触发这个节点生成（当前支持 AI 视频 / AI 图片 / 分镜生成 / 全景） |
| **打开工作台** | 3D 类节点跳到「3D 导演台」或「预演」页 |
| **复制 / 删除** | 复制节点或删掉 |
| **成组 / 解组** | Ctrl+G 把选中的节点包进一个组 |

#### 端口与连线

节点之间靠**端口**连接。端口有 8 种类型（图片 / 视频 / 音频 / 文本 / 资产 / 色板 / 遮罩 / 导出），**只有类型兼容才能连**。

操作：从节点右侧的圆点拖出 → 松开在空白处会弹出「只列可连接节点」的菜单 → 选一个自动创建并连上。

#### 右下角小地图

显示整个画布缩略图，可拖动、可缩放。

#### 画布 AI 助手（右上角「AI」按钮）

点开后有对话面板，可以直接用自然语言操作画布：

```
列出节点
概览
列出素材 类型:character
技能列表
把 n1 的标题改为 新标题
删除 n1
插入图片 assets/xxx.png
```

上方的四个开关是**权限位**：
- **可改画布** — 允许 AI 改节点
- **可花钱** — 允许 AI 触发生成（默认关）
- **可删除** — 允许 AI 删节点
- **自动执行** — 跳过逐步确认

#### 底栏

显示节点数、连线数、缩放比例、"自动保存 800ms · 撤销 12 步"。

> 画布**自动保存**：改动后 800ms 自动落盘，不用手动存。

| 元素 | 作用 |

### 4. H3 工坊 `#/h3`

**作用**：把一整集剧本处理成可出片的资产 + 合成成片。

#### 两个 Tab

**工坊 Tab**
| 字段 | 作用 |
|---|---|
| **输入方式** | 本地目录（选文件夹）/ 粘贴文本 |
| **集数** | 这是第几集 |
| **画幅** | 16:9 / 9:16 等 |
| **目标时长** | 每段最短/最长秒数 |
| **台词语言** | 中文 / 日语 / 英语 |
| **画面风格** | 全局风格描述 |
| **作品名** | 可选 |

点「分析」→ 得到：
- **分段列表**：每个分段的场景、动作、台词、说话人、估算时长
- **资产清单**：提取出的角色 / 场景 / 道具 / 音色

点「导入资产」→ 把这些资产**真正写进素材库**。

**成片 Tab**
| 字段 | 作用 |
|---|---|
| **视频片段** | 选择要拼接的视频文件 |
| **字幕** | 可选 .srt 路径 |
| **输出** | 合成后的 mp4 |

点「合成」→ 用 ffmpeg 拼接 + 烧字幕。

### 5. 剧本 `#/script`

**作用**：5 阶段剧本流水线。

#### 故事设定（顶部）

| 字段 | 作用 |
|---|---|
| **作品名** | 剧本标题 |
| **题材** | 14 种：玄幻 / 仙侠 / 武侠 / 都市修仙 / 都市重生 / 末世 / 科幻 / 灵异 / 宫斗 / 电竞 / 娱乐圈 / 年代重生 / 机甲 / 种田 |
| **集数** | 1-200 集 |
| **一致性上限** | 检查结果最多显示几条（1-10） |
| **一句话故事** | 决定整个故事走向，最重要的一栏 |

下方会提示所选题材的典型要素。

#### 五阶段卡片

| 阶段 | 产出 | 说明 |
|---|---|---|
| **大纲** | 三幕结构 + 每幕集数区间 + 核心节拍 | 一句话故事 → 结构化 |
| **人物小传** | 每个角色的欲望/需求/创伤/弧光/关系 | |
| **章节目录** | N 集，每集标题 + 一句话概要 + 所属幕 | |
| **章节正文** | 指定集数的场次、动作、台词 | 填「针对第几集」 |
| **视觉分镜** | 镜头表：景别、动作、运镜、时长 | 需先生成正文 |

每张卡片右上角有绿勾表示已完成。点「生成」单独跑该阶段，或点右上角「一键跑完」全跑。

#### 结果区

- **大纲**：标题、题材、集数、logline、三幕卡片
- **人物小传**：角色卡片（欲望 / 需求 / 创伤 / 弧光）
- **章节目录**：逐集列表
- **章节正文**：场次 + 动作 + 台词
- **视觉分镜**：镜头序号、运镜、描述、时长
- **一致性检查**：错误/警告列表（集数缺口、未登场角色、空台词等）

### 6. 漫画 `#/comic`

**作用**：文本 → 分镜板 → 出图 → 导出页面。

| 字段 | 作用 |
|---|---|

| **页数** | 生成几页 |
| **版式** | 11 套：整页单格 / 横双格 / 竖双格 / 四宫格 / 三横格 / 六宫格(2×3) / 六宫格(3×2) / 上宽下双 / 上双下宽 / 五格分布 / 条漫四格 |
| **场景描述** | 全局场景，会拼进每格的提示词 |

#### 流水线面板（15 站）

显示漫画的完整流水线，标注每个站的费用：

- 🟢 **零费用**：表演提示 / 排版出页 / 场景道具归并 / 提示词计划 / 单页重拼 / 体检 / 按规格导出

- 🟡 **出图花钱**：形态 / 修图 / 设定图提示词

> 当前已实现全部 7 个零费用站 + 分镜抽取 + 出图。

#### 发布前体检

7 项检查：有页面 / 每页有分格 / 每格有内容 / 气泡有说话人 / 分格不越界 / 每页有版式 / 页数合理。

#### 页面预览

每页显示：
- 页码、格数、当前版式
- **版式下拉框**：换版式（只重排这一页）
- **导出**按钮：导出这一页 SVG
- **分格预览**：按几何比例画出格子；已出图的格子显示真实图片

#### 导出

导出的 SVG 会把已生成的格图**内嵌成 base64**，文件自包含，可直接打开或转 PDF。

### 9. 提示词 `#/prompt`

**作用**：按 H3 官方六段式规范，可视化编辑提示词。

#### 四步流程

**① 画风与模式**

| 区块 | 作用 |
|---|---|
| **生成模式** | T2VA 文生视频 / I2VA 图生视频 / FL2VA 首尾帧 / L2VA 尾帧收敛 / Ref2VA 全参考 |
| **画风库（9 种）** | 地狱把妹王(外观版/画风版) / 90年代OVA / 新海诚 / 吉卜力 / 经典美式卡通 / 飞碟社 / 三渲二+PBR / GoHands |
| **自定义画风** | 英文描述，写了就覆盖预设 |
| **时长** | 4-15 秒 |
| **台词语言** | 中文/日语/English |
| **SCENE LAYOUT** | 全局场景 |
| **summary** | 一句话概括（留空自动生成） |
| **overall_soundscape** | 画内音（**规范要求不能空**） |
| **non_diegetic_music** | 画外配乐（无则填 N/A） |

标「改外观」的画风会改变人物比例，其余只改渲染风格。

**② 角色定义**

每个角色填：
- 名字、参考图序号、性别、身高
- **关键特征**（发色/瞳色/配饰）← 最重要
- 性格、音色描述

> **音色只在这里绑定一次**，分镜里只写 `(S1)` + 情绪，不重复。

**③ 分镜表**

每段填：
- 起止秒数、景别（大远景→大特写）
- 动作描述、运镜、音效
- 说话人、台词、情绪

**④ 编译结果**

编译后显示：
- 模式徽章、字符数、上限（7000）
- 警告列表（超限、字段为空等）
- 完整提示词（可一键复制）

### 11. 图像 `#/image`

**作用**：H3-Image 直接文生图。

#### 模型状态面板

显示：
- **模型就绪 / 缺失**徽章
- 当前用的模型文件名
- 采样参数：**6 步** / **guidance 1** / **无 CFG**
- 缺失时会列出缺哪些文件

> 采样参数由 checkpoint 蒸馏固定，**没有可调项**；该模型**不支持负面提示词**，请用正向描述。

#### 提示词

长文本框，最多 **4096 token**。越长越准，建议写完整的画面描述。

#### 输出设置

| 字段 | 作用 |
|---|---|
| **尺寸** | 12 种预设：自动 2048² / 方图 2048² / 竖图 3:4 / 横图 4:3 / 人物卡 2:3 / 视频竖 9:16 / 视频横 16:9 / 电商方图 / 电商竖 4:5 / 漫画页 3:4 / 4K 方图 4096² / 4K 横 5472×3072 |
| **种子** | 留空随机；固定种子可复现 |

#### 最近任务

显示出图任务列表：ID、状态、大小，可点「查看」预览。

## 三、典型工作流

### 场景 A：做一条 5 秒动画短片

1. **项目** → 新建项目
2. **素材库** → 上传角色立绘
3. **提示词** → 选画风、填角色、写分镜 → 复制编译好的提示词
4. **画布** → 新建 AI 视频节点，粘贴提示词，连上图片节点作参考
5. 点节点右键 → **运行**
6. **任务** → 看进度（约 130 秒）
7. 完成后节点上会显示视频

### 场景 B：做一套电商产品图

1. **模特** → 新建作业，模式选「电商拍摄」
2. 填模特描述、服装、风格、尺寸、张数
3. 创建后进详情看镜头清单和提示词
4. 触发出图（约 1-2 分钟/张）
5. **素材库** → 查看产物

### 场景 C：把立绘做成设定集

1. **人设卡** → 选立绘
2. 填角色描述、服装清单（一行一件）、表情集
3. 选「完整人设卡」档位
4. 点「预览提示词」确认无误
5. 点「生成拆解图」（约 90 秒）

### 场景 D：漫画一格

1. **漫画** → 输入分镜文本 → 选版式 → 点「分镜抽取」
2. 点「提示词计划」检查每格提示词
3. 点「逐格出图」
4. 回到页面看分格预览里的实际图片
5. 点「导出」得到内嵌图片的 SVG

### 场景 E：用白模预演控制构图

1. **3D 导演台** → 在 3D 舞台里摆好站位、设好机位
2. **预演 → 提示词** → 生成运镜描述
3. 用截图工具截下 3D 视口，或调用 `/previz-shot/capture` 自动截图+裁剪
4. **图像** 或用 `/previz-shot/generate`，把白模截图当参考图出成片

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面报 `BAD_RESPONSE` | 浏览器缓存了旧端口页面 | `Ctrl+Shift+R` 硬刷新 |
| 顶栏 H3 灯不亮 | ComfyUI 没启动 | 见部署 skill |
| 图像生成报模型缺失 | 模型没下载或路径不对 | 见部署 skill 第 3 节 |
| 生成很慢（首次） | 模型首次加载 | 正常，后续会快 5-10 倍 |
| 中文标注显示方块 | 字体问题 | 插件会自动探测，若仍失败检查系统字体 |
| 画布节点点了没反应 | 该节点暂不支持生成 | 当前支持：AI 视频 / AI 图片 / 分镜生成 / 全景 |
