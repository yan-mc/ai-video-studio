> 版本：1.0.0 · 更新：2026-11-13
> 界面入口：`http://127.0.0.1:<你的DSH端口>/jiuzhang/app/`

## 一、界面总览

打开后你会看到三部分：

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：品牌名 + 后端状态灯 + 强调色 + 主题切换 + 语言   │
├────────┬─────────────────────────────────────────────┤
│        │                                             │
│ 左侧   │            主内容区                          │
│ 导航   │       （每个页面的具体功能）                  │
│ 13 项  │                                             │
│ 4 组   │                                             │
├────────┴─────────────────────────────────────────────┤
│ 底栏：当前项目名                                        │
└──────────────────────────────────────────────────────┘
```

导航分四组：**制作**（渲染/剧本/漫画/模特）、**资源**（素材库/角色卡/项目）、
**工具**（立绘拆解/3D 预演/画布/图像）、**系统**（任务/设置）。

### 顶栏三个状态灯

| 灯 | 含义 | 不亮怎么办 |
|---|---|---|
| **H3** | 本地 ComfyUI 是否连通 | 启动 ComfyUI（见部署 skill） |
| **Seedance Mock** | 云端后端状态；显示 Mock 表示无 API key | 在「设置」填 Seedance key 或保持 Mock |
| **Blender 预演** | Blender 是否就绪 | 打开「3D 预演」页看状态徽章 |

它们每 5 秒自动刷新，不用手动点。

### 顶栏右侧

- **强调色**：四个圆点，切换按钮/选中态的主色（朱砂红 / 靛蓝 / 金 / 松绿）
- **主题**：月亮/太阳图标，在「墨夜」（深色）与「宣纸」（浅色）间切换
- **语言**：中 / EN

### 1. 渲染 `#/render` ★主入口

**作用**：一条镜头在这里从选素材做到出片。

三栏布局：

| 位置 | 内容 |
|---|---|
| **左栏** | 角色卡勾选、参考图清单（显示 `<Picture N>` 编号）、参考视频（带「带上音轨」开关）、参考音频 |
| **中栏** | 渲染结果预览（视频直接播放 / 图片直接显示） |
| **右栏** | 模式、画风、时长、画幅、档位、种子、**参考图保真**、环境声、配乐、自定义画风、预算 |

#### 顶部

| 元素 | 作用 |
|---|---|
| **单镜头渲染 / 成片合成** | 两个 tab。成片合成可从项目镜头列表勾选片段并按顺序拼接 |
| **参考图 N/9** | 实时预算。超了会变黄/红 |
| **刷新 / 开始渲染** | — |

#### 底部：提示词编辑器（可折叠）

- 默认显示自动编译的提示词（含 `subject_definitions`、`<Picture N>` 引用）
- 「改为手工编辑」可覆盖
- 「套用模板…」从工具箱的 20 条提示词模板里插入片段

#### 参考图保真档位

| 档位 | 效果 | 何时用 |
|---|---|---|
| **跟随生成面积**（match） | 快，日常首选 | 默认 |
| **最高保真**（max） | 短边固定 2048，一致性更好，**明显更慢** | 角色细节要求高、显存充足时 |

> 显存不足时（空闲 < 4G）会自动降为 match，并在预算面板标注「已降级（请求 max）」——
> **不会静默降级**。

### 6. 角色卡 `#/vault` ★新

**作用**：管理角色的「设定卡图 + 文字设定」，是跨镜头一致性的锚点。

每张卡包含：

| 字段 | 说明 |
|---|---|
| **名称 / 别名** | 提示词里用得到 |
| **四个图片槽位** | 设定卡（sheet）/ 原立绘（origin）/ 头部特写（heads）/ 额外（extras） |
| **文字设定** | 关键特征、性格、声音描述 |
| **引用策略** | `sheet-first`（默认，最稳）/ `sheet-only` / `origin-first` / `both` |
| **每卡出图数** | 默认 1 张 —— 多角色时每卡 1 张最稳 |

> 提示词里的 `<Picture N>` 编号由后端按**实际上传顺序**算，
> 不是按卡的序号。所以别自己推，调 `/render/plan`。

### 8. 立绘拆解 `#/breakdown`

**作用**：把一张立绘做成**全景式角色概念分解图**（服装分层/表情集/材质特写/随身物品）。

> 这就是原来的「人设卡拆解」，现在只表示**工具本身**。
> 做出来的图存进「角色卡」才叫角色卡。

#### 三档强度

| 档位 | 产出 |
|---|---|
| 标准 | 中心立绘 + 服装分层 + 表情集 |
| 完整 | 再加材质特写 |
| 零件 | 聚焦单个部件 |

#### 关键：角色名只作为称呼

输入框里只填**角色名**即可（如「三角初华」）。
长相、发型、配色一律以参考图为准，**不要用文字描述外观** ——
参考图是直接进模型的，文字复述外观会和图像打架。

### 9. 3D 预演 `#/previz`

**作用**：用 Blender 渲出 H3 的**控制通道**（depth/pose/canny/gray），逐帧约束结构与运动。
这是目前**最可靠**的构图控制手段 —— 比纯提示词稳定得多。

#### 页面上的三件事

| 区块 | 作用 | 耗时 |
|---|---|---|
| **动画预览** | 渲一段彩色灰模动画，直接播放 —— 你能看到"我到底做了个什么动画" | 72 帧 **4 秒** |
| **控制通道** | depth / pose / canny / gray 四选一，产物给 H3 用 | 124 帧 **20 秒** |
| **在 Blender 中编辑** | 用桌面 Blender 打开 `.blend`，随便调 | 立即 |

> 预览用 Workbench MATERIAL 着色（演员按 `color` 上色）；
> 控制通道用 EEVEE（depth/pose）或 Workbench 灰模（canny/gray）。

#### 摆走位在「渲染页」，不在这里

角色/道具/机位在**渲染页 → 3D 走位**面板里编辑（与镜头卡同源），预演页只负责渲。
这样"改参数"和"看结果"在同一份数据上，不会对不上。

走位字段：`actors[]`（名字/身高/配色/坐标/动作/起止帧）、`props[]`（灰盒或导入模型）、
`camera3d`（机位 + 关键帧）。坐标系 **`(x=左右, y=高度, z=深度)`**。

> 没配 `actors` 时只能用「默认两人对峙」占位 —— 那只能验证链路，不是真实预演。

#### 四个控制通道怎么选

| 通道 | 适合 | 说明 |
|---|---|---|
| **depth**（推荐） | 绝大多数情况 | 锁走位/遮挡/景深，最通用 |
| **pose** | 动作戏 | 只出人物剪影，道具和背景不约束 |
| **canny** | 建筑/道具结构 | 白底黑线边缘图 |
| **gray** | 光影布局 | 整体灰模 |

#### 导入外部模型

把 `.glb / .gltf / .fbx / .obj` 放进 `<dataDir>/assets/3d/`（或 `assets/`），
「3D 走位」面板的「模型」下拉会自动列出。选中后会按**包围盒高度**归一化到指定身高，
并自动读出模型内置的动作名（Mixamo 的 Action 名形如 `Armature|Armature|walk`）。

> ⚠️ Blender 是 **Z-up**，插件内部会做坐标换算。
> 直接改 `scene.json` 时要记得这一点，否则人偶会"躺平"或画面全黑。

### 10. 画布 `#/canvas`

**作用**：节点式工作流编排。26 个节点，8 种端口类型。

画布是无限大的，可以放各种节点、连线，数据从上游流向下游。

#### 顶部工具条

| 元素 | 作用 |
|---|---|
| **新建节点** | 打开分类菜单，8 个分组：文本 / AI 提取 / 图片 / 智能体 / 音频 / 视频 / 导演台 / 全景 |
| **撤销 / 重做** | 支持 12 步 |
| **缩放** | 缩小 / 百分比 / 放大 / 适应视图 |
| **锁定画布** | 锁定后节点不能拖动、不能连线，防误触 |
| **节点数 / 连线数** | 实时统计 |

#### 画布空白处右键

- 新建节点
- 粘贴（Ctrl+V 剪贴板内容）
- 全选
- 清空画布

#### 节点上右键

| 菜单项 | 作用 |
|---|---|
| **运行** | 触发这个节点生成（当前支持 AI 视频 / AI 图片 / 分镜生成 / 全景） |
| **打开工作台** | 3D 类节点跳到「3D 预演」页 |
| **复制 / 删除** | 复制节点或删掉 |
| **成组 / 解组** | Ctrl+G 把选中的节点包进一个组 |

#### 端口与连线

节点之间靠**端口**连接。端口有 8 种类型（图片 / 视频 / 音频 / 文本 / 资产 / 色板 / 遮罩 / 导出），**只有类型兼容才能连**。

操作：从节点右侧的圆点拖出 → 松开在空白处会弹出「只列可连接节点」的菜单 → 选一个自动创建并连上。

#### 右下角小地图

显示整个画布缩略图，可拖动、可缩放。

#### 画布 AI 助手（右上角「AI」按钮）

点开后有对话面板，可以直接用自然语言操作画布：

```
列出节点
概览
列出素材 类型:character
技能列表
把 n1 的标题改为 新标题
删除 n1
插入图片 assets/xxx.png
```

上方的四个开关是**权限位**：
- **可改画布** — 允许 AI 改节点
- **可花钱** — 允许 AI 触发生成（默认关）
- **可删除** — 允许 AI 删节点
- **自动执行** — 跳过逐步确认

#### 底栏

显示节点数、连线数、缩放比例、"自动保存 800ms · 撤销 12 步"。

> 画布**自动保存**：改动后 800ms 自动落盘，不用手动存。

### 11. 图像 `#/image`

**作用**：H3-Image 直接文生图。

#### 模型状态面板

显示：
- **模型就绪 / 缺失**徽章
- 当前用的模型文件名
- 采样参数：**6 步** / **guidance 1** / **无 CFG**

## 三、典型工作流

### 场景 A：做一条动画短片（推荐路径）

```
素材库 上传两张立绘
   ↓
立绘拆解 各做一张设定卡（约 90 秒/张）
   ↓
角色卡 建两张卡（设定卡 + 原立绘 + 文字设定）
   ↓
3D 预演 配走位 → 渲预览确认 → 渲 depth 控制序列
   ↓
渲染 勾两张卡 + 选 depth 控制视频 + 选画风 → 编译提示词 → 开始渲染
   ↓
页面内直接预览；多镜的话到「成片合成」tab 拼起来
```

### 场景 B：做一套电商产品图

1. **模特** → 新建作业，模式选「电商拍摄」
2. 填模特描述、服装、风格、尺寸、张数
3. 创建后进详情看镜头清单和提示词
4. 触发出图（约 1-2 分钟/张）
5. **素材库** → 查看产物（已自动归档）

### 场景 C：把立绘做成设定集

1. **立绘拆解** → 选立绘
2. 角色名**只当称呼填**（长相交给参考图，不要用文字描述外貌）
3. 选「完整」档位
4. 点「预览提示词」确认无误
5. 点「生成拆解图」（约 90 秒）
6. **角色卡** → 把拆解图登记成卡，供后续渲染引用

### 场景 D：漫画一格

1. **漫画** → 输入分镜文本 → 选版式 → 点「分镜抽取」
2. 点「提示词计划」检查每格提示词
3. 点「逐格出图」
4. 回到页面看分格预览里的实际图片
5. 点「导出」得到内嵌图片的 SVG

### 场景 E：用 Blender 白模控制构图（★ 最可靠）

1. **渲染页 → 3D 走位** → 加角色（名字/身高/配色/坐标/动作）、加道具、设机位
2. **3D 预演 → 动画预览** → 渲一段彩色灰模，确认走位对不对（4 秒）
3. 同一个卡片里点 **depth** → 渲控制通道（20 秒），返回的 `rel` 自动填进控制视频
4. **渲染页 → 控制视频** → 确认强度（1.0—1.5）与生效区间（0.0 → 0.85）
5. 勾角色卡 + 写提示词 → 显示开始渲染

> **提示词要描述画面里真实存在的东西**（人数、主要道具、机位方向）。
> 控制视频里是两人，提示词写"一个少女"，前几秒会被提示词抢走。

#### 长片怎么拆（分段串联）

H3 单镜训练范围是 **124—362 帧（5—15 秒）**，更长要拆段。

1. 每段渲自己的 depth 控制序列
2. 第 1 段生成完后，**抽末帧**：`ffmpeg -sseof -0.1 -i shot1.mp4 -frames:v 1 last.png`
3. 第 2 段镜头卡的 `previz.firstFramePath` 指向这张图（插件自动走 **Ref2VA + AddGuide**）
4. 每段起点必须等于上一段终点，否则拼起来会瞬移
5. 全部完成后 `ffmpeg -f concat` 拼接

> **为什么不能用 I2VA**：它没有 `ref_images` 输入口，用了就挂不上角色卡，两张脸会飘。
> Ref2VA 支持参考图，AddGuide 在首帧锚一张图，两者共存。

### 场景 F：从零做角色设定（完整闭环）

```
剧本页「剧本拆解」tab  → 一集剧本 → 分段 + 角色/场景/道具清单（纯文本）
   ↓
按清单去素材库准备立绘 / 或用图像页生成
   ↓
立绘拆解 → 设定卡 → 角色卡
   ↓
渲染页逐镜出片 → 成片合成
```

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面报 `BAD_RESPONSE` | 浏览器缓存了旧端口页面 | `Ctrl+Shift+R` 硬刷新 |
| 顶栏 H3 灯不亮 | ComfyUI 没启动 | 见部署 skill |
| 图像生成报模型缺失 | 模型没下载或路径不对 | 见部署 skill 第 3 节 |
| 生成很慢（首次） | 模型首次加载 | 正常，后续会快 5-10 倍 |
| 中文标注显示方块 | 字体问题 | 插件会自动探测，若仍失败检查系统字体 |
| 画布节点点了没反应 | 该节点暂不支持生成 | 当前支持：AI 视频 / AI 图片 / 分镜生成 / 全景 |
