# 插件架构与接口规范

> 注：本文件为历史归档，其中的软件名已中性化处理。

> 配套《方案总览.md》《资产包与挂载规范.md》《模型适配规范-H3与Seedance.md》。定义 DSH 插件的模块、Host 工具、Client 页面、数据模型、任务流与目录结构；不含实现代码。

## 1. 仓库与进程结构

```
F:\AI视频\工作室\
├─ dsh-ai-video-studio\          # DSH bundle（Host + Client）
│  ├─ package.json               # dsh.bundle.patch + dsh.client
│  ├─ cordis.patch.yml
│  ├─ src\host\                  # Node/TS：工具/服务/适配器/资产/队列
│  ├─ src\client\                # React 主面板
│  ├─ src\shared\                # 类型/schema/常量
│  └─ vendor\                    # 复用产物（预演软件引擎、节点动画软件/视频增强软件 schema 等）
├─ services\previz\              # 3D 预演服务（预演软件引擎 port 或 sidecar 包装）
├─ services\pipeline\            # OpenCineAgent 流水线（可选）
├─ data\                         # 项目/镜头/任务/输出/mounts.json
├─ exports\                      # 成片导出
└─ logs\
```

- **Host**：工具、服务、Web 路由、文件服务。
- **Client**：`sidebar.panellist` 图标 + `main` 主面板；不直连外部服务（预演 iframe 除外，若最终选择）。
- **外部进程**：ComfyUI/SGLang、FFmpeg、可选 OpenCineAgent、可选 sidecar；全部由 Host 的 ServiceManager 管理（启动/健康/停止/日志）。

## 3. Client 主面板

| 页面 | 内容 | 阶段 |
|---|---|---|
| 项目/镜头 | 项目树、镜头列表、状态筛选、批量 | P0 |
| 镜头卡 | 模式/时长/风格/描述/运镜/台词/角色/参考图/首尾帧/手动提示词；编译预览 | P0 |
| 任务 | 队列/运行/失败/重试/成本/ETA | P0 |
| 预览/审片 | 视频预览、take 对比、QC 报告 | P1 |
| 后处理 | 模型选择器（视频增强软件 schema 驱动）、预设、tile/显存提示、编码器、A/B | P1 |
| 3D 预演 | 场景/机位/动作、导出参考视频/深度/首尾帧 | P2 |
| 资产 | 包列表、挂载/卸载/校验/启用、来源台账 | P0 |
| 动效 | 模板/信息图/片头（节点动画软件 schema 驱动子集） | P3 |
| 设置 | 后端地址、profile、并发、成本、路径 | P0 |

交互约定：

- 生成前显示"后端能力 + 预计成本/时长"；超限直接拦截。
- 所有长任务走任务页；失败可重试、可切换后端。
- 资产缺失给出"缺哪个包、从哪里挂载"的可操作提示。

## 4. 数据模型（核心）

```ts
interface Project { id; name; category; rootDir; createdAt; updatedAt; }
interface Episode { id; projectId; name; index; }
interface Scene { id; episodeId; name; description; assetRefs: string[]; }
interface Shot {
  id; projectId; sceneId; title; mode: 't2v'|'i2v'|'fl2v'|'ref2v';
  durationSec; ratio; style; description; camera; dialogue; soundscape; music;
  subjects: Subject[]; refs: { images: AssetRef[]; videos: AssetRef[]; audios: AssetRef[] };
  keyframes: { first?: AssetRef; last?: AssetRef };
  control?: { type: 'depth'|'canny'|'pose'; ref: AssetRef; strength: number };
  previz?: { engine: 'previs'|'预演工作台'|'blender'; projectId?; refVideo?; depth?; firstFrame?; lastFrame? };
  backend: string; profile?: string; promptOverride?: string;
  status: 'draft'|'ready'|'generating'|'review'|'done'|'failed';
  version: number;
}
interface Take { id; shotId; jobId; outputs: OutputFile[]; qc?: QcResult; selected: boolean; createdAt; }
interface Job { id; backendId; mode; status; remoteId?; paramsHash; promptHash; cost?; error?; createdAt; updatedAt; }
interface AssetRef { packId: string; entryId: string; }
```

- 单一事实源：`data/projects/...` + SQLite 索引（可选）。
- 幂等键：`shotId+version+backendId+paramsHash`；相同键不重复提交。
- 每次生成记录：模型/资产包版本/参数/seed/输入哈希/最终提示词。

## 5. 任务流

```text
镜头卡 → 编译提示词 → 能力校验 → 解析资产引用 → 选后端（本地/云端/mock）
      → 提交（Job）→ 轮询（状态/ETA）→ 下载输出（Take）→ QC
      → 通过 → 后处理（超分/补帧/字幕/混音）→ 成片 → 导出+台账
      └ 失败 → 分类错误 → 重试/降级/切后端 → 任务页可见
```

- 并发：本地 1（12GB 串行）；云端可配 1—3。
- 取消：本地通知 ComfyUI 中断；云端调取消接口（若支持）。
- 恢复：任务落盘；重启后未完成任务重新轮询/重提。

## 8. 错误与安全

- 错误码：`ASSET_PACK_NOT_MOUNTED / ASSET_HASH_MISMATCH / BACKEND_UNREACHABLE / MODEL_MISSING / VRAM_INSUFFICIENT / INVALID_INPUT / RATE_LIMITED / TIMEOUT / DOWNLOAD_FAILED`。
- 路径边界：文件服务只允许 data/exports/挂载包根目录内。
- 凭据：只存凭据服务/环境变量，不写项目文件。
- 外部调用默认关闭；开启需显式配置。
- 来源台账：每次挂载/拷贝/生成写记录。

## 9. 测试策略（软件端）

1. **mock 后端**：无需 API，验证全链路。
2. **适配器契约测试**：capabilities/参数校验/错误映射。
3. **资产挂载测试**：挂载/卸载/缺包/哈希/许可禁用。
4. **任务恢复测试**：重启/失败重试/取消。
5. **UI 冒烟**：项目→镜头→生成→预览→后处理→导出。
6. **真机测试（后置）**：H3 本地、Seedance 云端、12GB 性能。
