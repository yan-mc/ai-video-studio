# AI 视频工作室（DSH 插件）实施方案

> 注：本文件为历史归档，其中的软件名已中性化处理。

> 配套《方案总览.md》《插件架构与接口规范.md》《资产包与挂载规范.md》《模型适配规范-H3与Seedance.md》《复用与REA深挖计划.md》。
> 范围：**软件端先行**；API Key/云端账号/真实模型测试后置。不含实现代码。

## 1. 阶段划分与验收

### P0 骨架（软件端可演示，无需任何 API）

**内容**

1. 插件仓库 `F:\AI视频\工作室\dsh-ai-video-studio\`：Host/Client 骨架、bundle patch、可安装/卸载。
2. 资产挂载层：`AssetRegistry/MountManager/Validator` + 资产页（挂载/卸载/校验/启用）。
3. `VideoBackend` 接口 + `mock` 后端（FFmpeg 生成占位视频）。
4. 项目/镜头卡/任务数据模型 + 本地文件服务。
5. 主面板：项目/镜头/任务/预览/资产/设置 六页 MVP。

**验收**

- 安装插件 → 面板出现"视频工作室"→ 新建项目/镜头 → 编译提示词（无后端也可编译）→ mock 生成 5 秒视频 → 预览 → 导出。
- 挂载一个资产包（如 `node-schema-ref`）→ 校验通过 → 任务引用解析成功；卸载后引用报 `ASSET_PACK_NOT_MOUNTED`。
- 重启后任务/项目状态保留。

### P1 本地 H3 闭环（软件端优先，真机可后测）

**内容**

1. `h3-local` 适配器：ComfyUI HTTP 客户端、工作流模板加载、probe/poll/fetch、错误映射。
2. 提示词编译器：六段式/三段式/标签/校验/字符与参考组限制。
3. 任务队列：并发 1、重试、取消、恢复、成本记录。
4. 后处理页：视频增强软件 schema 驱动的模型选择器/预设/tile 提示；FFmpeg 转码/拼接；SeedVR2/RIFE 预留。
5. QC：文件有效性/时长/音频轨/首帧抽帧/SSIM 计划。

**验收（无 API 时用 mock+工作流模拟；有环境后真机）**

- 镜头卡 → 提示词 → ComfyUI（或 mock）→ take → 预览 → 超分（若可用）→ 导出。
- 12GB profile 选择生效（P12-draft）。
- 后端不可达/模型缺失/显存不足给出可操作错误。

### P2 3D 预演（复用预演软件引擎）

**内容**

1. `vendor/previs-director/` 汇编：recovered JS（engine/server/three/MCP SDK）+ tool_catalog/data_model/http_api/validation_rules + catalog 数据。
2. port：`store/engine/catalog/tools`；数据格式保持 v1；`PREVIZ_HOME` 指向工作室数据目录。
3. 预演页：项目/镜头/元素/动作/机位/关键帧编辑；校验；导出 JSON/首尾帧/参考视频（渲染先外部/后内置）。
4. 资产包：`previs-3d-core`（guo 仅本地）、`previs-3d-cc0`（fuka CC0）、`previs.asset-index`（清单）。
5. 与生成联动：`shot.previz` 字段 → H3 首帧/尾帧/控制视频/参考图。

**验收**

- 在 DSH 面板建一个预演工程，放 2 人物+道具，设机位/动作，跑 16+6 校验，导出工程 JSON；与预演软件 sidecar 同输入 golden 对照一致（字段/校验）。
- 挂载 CC0 资产包，场景/道具可被引用；未挂载时给出明确错误。
- 把预演首帧/尾帧绑定到镜头卡，生成任务参数中包含对应资产引用。

### P3 多镜/Seedance/动效

**内容**

1. `seedance-cloud` 适配器：创建任务/轮询/下载/错误映射/能力校验（API Key 后置）。
2. 多镜：尾帧继承、角色卡、场景锚点、10/30 秒拼接、字幕/混音、OTIO 时间线。
3. 动效页：节点动画软件 schema 驱动 10—20 节点子集 + 模板（片头/标题/信息图）+ Remotion/FFmpeg 渲染。
4. 审片/批量/成本。

**验收**

- 10 秒（2 镜）/30 秒（4—6 镜）作品：镜头连续、音频可用、字幕/导出完整。
- Seedance 适配器在 mock 模式下通过契约测试；真机待 Key。

### P4 收尾

- 稳定性/性能/文档；来源台账与许可审计；安装/升级/迁移说明。

## 2. 里程碑时间（软件端，1 人全栈估算）

| 阶段 | 预估 | 交付 |
|---|---|---|
| P0 | 1—2 周 | 可安装插件 + mock 闭环 + 资产挂载 |
| P1 | 2—3 周 | 本地 H3 适配 + 后处理页 + 任务恢复 |
| P2 | 3—4 周 | 预演软件引擎 port + 预演页 + 3D 资产包 |
| P3 | 3—4 周 | Seedance + 多镜 + 动效页 |
| P4 | 1—2 周 | 收尾/审计 |
| 合计 | **10—15 周** | 软件端 v1 |

> 不含模型下载、API 环境、真实素材、法务时间。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 预演软件 engine port 成本/隐藏依赖 | P1 先"port 核心 + 外部渲染"；golden 对照 sidecar；REA R1/R2 补 |
| 12GB 显存不足 | P12-draft 480p/8 步；超分交付；云端 Seedance 兜底 |
| Seedance API 限制（真人脸/额度） | 适配器前置校验；虚拟人像/授权素材；Key 后置 |
| 资产许可（guo/预演软件内部） | `distribution:forbidden` 仅本地；台账；不分发 |
| 视频增强软件/节点动画软件只能参考 | 数据包 + 运行时自研；REA 补未知 |
| 任务/进程崩溃 | 落盘/幂等/恢复；ServiceManager 健康检查 |
| 面板复杂度 | P0 只做六页；其余逐步加 |

## 5. 测试计划（软件端）

| 测试 | 方式 | 通过标准 |
|---|---|---|
| 插件安装/卸载 | DSH plugin_manager | 面板/工具注册正常，卸载无残留 |
| mock 闭环 | 无外部依赖 | 项目→镜头→生成→预览→导出 |
| 适配器契约 | 单测/mock | capabilities/参数校验/错误映射 |
| 资产挂载 | 挂载/卸载/缺包/哈希 | 引用解析正确，错误可诊断 |
| 任务恢复 | 杀进程/重启 | 状态恢复，不重复提交 |
| 提示词编译 | 固定用例 | 六段式/三段式/标签/限制校验 |
| 预演引擎 | golden vs sidecar | 状态/校验一致 |
| 后处理/动效 | 样例素材 | 输出可播放/时间线正确 |
| 端到端 | 有环境后 | H3 本地 + Seedance 云端各 1 条 |

## 6. 交付标准（Definition of Done）

1. 插件可安装、可卸载、可升级；无外部资产依赖即可启动。
2. 资产全部外置且可挂载；缺包错误可操作。
3. mock 闭环 100% 通过；H3/Seedance 适配器契约测试通过。
4. 预演引擎与预演软件 sidecar golden 对照一致（状态/校验）。
5. 任务可恢复、可重试、可切换后端。
6. 来源台账完整；无闭源资产随插件分发。
7. 文档：安装/配置/资产包/适配器/REA 记录齐全。
