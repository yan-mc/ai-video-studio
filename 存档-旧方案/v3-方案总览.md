## 1. 目标与范围

### 1.1 目标

做一个 **DSH Web 插件**（Host + Client），完成"项目→镜头卡→提示词→本地/云端生成→3D 预演→后处理→成片"的**软件端闭环**；模型调用统一走适配器，本地 H3 与云端 Seedance 都是可替换后端。

### 1.2 本期做（软件端）

- DSH 插件骨架：Host 工具/服务、Client 主面板、任务队列、本地文件路由。
- 资产系统：**全部资产外置**为可挂载资产包；插件本身不含模型/3D/素材。
- 模型适配器：`h3-local`（ComfyUI/DiffSynth）、`seedance-cloud`（火山方舟）、`mock`；统一接口与能力描述。
- 3D 预演：大面积复用预演软件拆解产物（director 引擎/资产/工具），做成可挂载的"预演服务 + 3D 资产包"。
- 后处理/动效：复用视频增强软件/节点动画软件的 schema/数据包，运行时用 FFmpeg/开源模型/Remotion 实现。
- 配音：先 H3 原生音频；RVC/TTS 只预留插件接口，后续接入。

### 1.3 后续做（API/测试阶段）

- Seedance 火山方舟 API Key、模型 ID、额度、限流。
- H3 官方 API（2K/Regenerate）与云端 GPU（如启用）。
- RVC/TTS 插件对接（其他项目产物）。
- 真实素材/账号/授权与法务审计。

## 5. 资产外置与挂载（摘要）

- **原则**：插件只带代码；资产全部在外部目录，通过 `mount` 注册。
- **目录**：`F:\AI视频\资产包\<pack-id>\`（可配置根目录）；每个包含 `manifest.json` + 内容文件。
- **包类型**：`model`（H3 权重/VAE/TE/LoRA）、`3d`（场景/骨架/道具/动作/姿势）、`motion`（动效模板/预设）、`schema`（节点动画软件/视频增强软件定义）、`template`（提示词/分镜模板）、`audio`（音效/音乐/人声参考）、`font`、`doc`。
- **挂载**：`AssetRegistry.mount(packId, path)` / `unmount`；DSH 面板"资产"页可视化挂载/校验/启用禁用；任务提交前解析引用，缺包给出可操作错误。
- **清单 schema**：`manifest.json` 含 `id/kind/version/license/source/entries[]/requirements`；每个 entry 含 `id/type/path/bytes/sha256/tags/deps`。
- **接口**：`AssetResolver.resolve(ref)`、`AssetPackLoader.load`、`AssetValidator.verify`；所有模块通过 ID 引用资产，不写死路径。
- 详细规范见 `资产包与挂载规范.md`；全量盘点见 `研究资料/11-外置资产包清单.md`（整理中）。

## 6. 模型适配（摘要）

统一接口：

```ts
interface VideoBackend {
  id: 'h3-local' | 'seedance-cloud' | 'mock' | string;
  capabilities: {
    maxDurationSec: number;        // H3 15s / Seedance 2.5 30s
    nativeAudio: boolean;
    refImages: number;             // H3 9 / Seedance 2.5 30
    refVideos: number;             // H3 3 / Seedance 2.5 10
    refAudios: number;             // H3 3 / Seedance 2.5 10
    firstFrame: boolean; lastFrame: boolean;
    resolutions: string[];         // 480p/768p/720p/1080p...
  };
  submit(input: BackendInput): Promise<JobHandle>;
  poll(handle: JobHandle): Promise<JobStatus>;
  fetch(handle: JobHandle, dest: string): Promise<OutputFile[]>;
  cancel?(handle: JobHandle): Promise<void>;
}
```

- **h3-local**：ComfyUI HTTP（GGUF/NF4；480p/768p profile）或 SGLang `/v1/videos`；12GB 走 480p/8 步 Turbo。
- **seedance-cloud**：火山方舟 `POST /api/v3/contents/generations/tasks`；支持文生/首帧/首尾帧/全模态参考（2.5：图 0—30、视频 0—10、音频 0—10、30 秒直出）；轮询任务查结果；API Key 后置。
- **mock**：本地生成占位视频（ffmpeg 色块），用于软件端联调，不需要任何 API。
- 适配器返回统一 `Job`/`Take` 结构；成本、限流、错误映射在适配器内。
- 详细字段见 `模型适配规范-H3与Seedance.md`。

## 8. 工程规则

- 插件仓库只含自研代码；拆解产物放 `vendor/` 并登记来源/许可/commit。
- 不写死路径/端口/模型名；全部走配置 + 资产包 + 适配器。
- 每个任务落盘可恢复；幂等键 `shotId+version+backend+paramsHash`。
- 默认本地/离线；云端调用需显式启用。
- 许可证工程阶段不阻塞；完工后按来源台账审计。
