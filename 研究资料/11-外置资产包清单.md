## 5 manifest schema 建议（所有资产包共用）

一个资产包 = 一个目录 + `manifest.json`；mount 只登记“入口”，不复制内容。建议字段：

| 字段 | 类型 | 说明/校验 |
|---|---|---|
| `id` | string | 包唯一 id（建议 `mount id` 同值，如 `previs.fuka.props`） |
| `kind` | enum | `asset | model | schema | scene | motion | webapp | index` |
| `version` | string | 包版本（`1.0.0`；源版本另放 `source.version`） |
| `license` | object | `spdx`（必填，未知写 `NOASSERTION`）、`name`、`url`、`commercial`、`redistribute`（bool）、`note` |
| `source` | object | `type(hf/github/local/web)`、`url`、`revision/commit`、`retrievedAt`、`originalPath` |
| `hash` | object | `algorithm:"sha256"`、`files`（计数）、`rootHash`（可选 Merkle/清单 hash） |
| `entries` | array | 每项 `{path, bytes, sha256, format, type, metadata{...}, license?}`；2198 条级清单参考 `previs.assets.manifest` v1 |
| `requirements` | object | `engine`（如 ComfyUI≥0.30）、`vramGB`、`ramGB`、`diskGB`、`python/node`、`deps[]`、`profiles[]`（12g/16g/24g） |
| `mount` | object | `mode:"read-only"|"cache"`、`pathHint`、`env`（如 `COMFYUI_MODELS`）、`verify:"sha256"` |
| `provenance` | array | 来源台账：拆解/下载/生成记录、是否随包分发、审核状态 |

**每种格式的接口要求**：

| 格式 | 必备校验 | 接口/加载要求 |
|---|---|---|
| GLB | sha256、面数/三角数、骨骼数、动画 clip 数、`license` | three.js/Unity/UE 加载；`models/` 只读；缺贴图报 `missing` |
| FBX | sha256、版本号（7400/7700）、rig 命名（mixamo/bip/其它）、骨骼数 | 需 rigProfile 声明；跨骨架要 retarget；不内嵌贴图时提示 |
| PNG/SVG（缩略图） | sha256、尺寸、色彩类型、对应 asset id | 懒加载；缩略图与模型/场景必须可反查 |
| JSON（poses/clips/scene/rig） | schema+version、joint 数、fps、坐标系/单位、sha256 | 按 schema 版本迁移；越界/NaN 拒绝；rig 必须显式（miorning/自有） |
| PMA（预演软件场景快照） | XOR 解码后 JSON、sceneObjects/bones/FOV、sha256 | 仅转换器读取；输出 three.js scene descriptor，不改原文件 |
| JS/HTML（闭源 web 应用） | sha256、入口 html、版本 | **不加载、不分发**；仅作为对照证据，manifest `handling:"reference-only"` |
| safetensors（H3 权重） | sha256、dtype、shard 序号/总数、HF revision、license | ComfyUI/SGLang 按目录约定加载；必须固定 revision；GGUF 排除 text encoder 视觉塔问题（另注） |
| 清单 CSV/JSON | 行数、字段完整性、sha256 覆盖 100% | mount 启动时校验 entries 数与 bytes 汇总；缺失即拒挂 |
