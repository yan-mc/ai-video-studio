# 方向二：中国厂商闭源/商用视频生成模型调研

> 报告基准日：**2026年11月3日（北京时间）** ｜ 数据抓取日：2026-11-03
> 范围：中国厂商的闭源/商用视频生成模型（含 API 与 C 端产品背后的模型）。开源模型（MiniMax H3、MAGI-2、混元等）仅在与闭源商用线直接相关处简述，并标注与方向三的交叉。
> 纪律：区分「官方宣称」「第三方评测」「媒体传闻」「推测」；无法核实标 ⚠️待核实；榜单 Elo 均注明抓取时点，**不同版本/不同时点的 Elo 不可直接比较**。

## 0 摘要与关键结论

1. **格局：四强＋两梯队。** 截至 2026-11，中国视频模型形成「阿里（Wan 3.0＋HappyHorse 1.1）、字节（Seedance 2.5）、快手（可灵 Kling 4.0）、MiniMax（Hailuo H3/H3 Max）」四强，加上生数 Vidu、爱诗 PixVerse、腾讯混元、智谱、百度、昆仑万维等第二梯队。
2. **榜单：中国模型在 AA 文生视频（含音频）榜前五占三席、前十占五席。** 2026-11-03 抓取 AA-Video-T2V v2.1：阿里 Wan 3.0 以 Elo 1172 全球第一，MiniMax H3（768p）1160 第三，字节 Dreamina Seedance 2.5 1155 第五；图生视频榜 Dreamina Seedance 2.5 以 1157 全球第一；视频编辑榜 Wan 3.0 以 1196 全球第一（[70][71][72]）。
3. **长镜头与原生音频成为 2026 下半年的主战场。** 可灵 4.0、Seedance 2.5、Wan 3.0 均把「单次 30 秒＋原生台词/BGM/音效＋多镜头」做成标配；可灵 4.0 的续拍最长可延展至 2 分钟（[1][14][27]）。
4. **「全模态参考」军备竞赛。** Seedance 2.5 单次支持 30 张图＋10 段视频＋10 段音频（合计 50 项）[14]；可灵 4.0 单次 15 项参考素材＋10 张关键帧[1]；Wan 3.0 单次最多 20 个多模态素材（图≤10、视频≤5、音频≤5，且支持文档/网页）[27]。
5. **价格两极分化。** C 端即梦三连涨（15 秒视频积分 45→120→VIP 通道 210，会员积分缩水）[19][20]；B 端可灵、阿里、MiniMax 持续降价，Wan 3.0 折后 0.21 元/秒（480P）起、HappyHorse 1.1 折后 0.54 元/秒（720P）、Seedance 2.0 mini 约 0.5 元/秒[19][28]。
6. **可灵商业化最快。** 2026Q1 营收超 6.5 亿元（同比 +300%），2026-03 ARR 近 5 亿美元；截至 2026-06 全球用户破 1 亿、企业客户近 5 万家；首轮独立融资实际到账约 198.02 亿元（约 29.05 亿美元）、投后估值约 180 亿美元，快手持股 68.33%[2][3][10][11]。
7. **MiniMax H3 是「半开源」。** 官方开放 H3-Base 的 FL2VA / Ref2VA 两个 checkpoint 权重（HF、魔搭），但 H3-Context-IR 与 H3-Regenerate-2K 未开源，2K 完整链路需配合官方 API；AA 因此将其列在「开放权重」序列并称其为开放权重第一[32][70]。
8. **HappyHorse 归属已定案：是阿里的。** 2026-04-08 匿名登顶 AA，2026-04-10 阿里 ATH 事业群公开认领（ATH 创新事业部，核心成员含前快手副总裁、可灵技术负责人张迪）；1.1 版于 2026-06-22 发布[23][24][19]。
9. **阿里 Wan 3.0 不开源。** 与 Wan 2.x 开源策略不同，Wan 3.0 仅通过百炼托管 API 提供，未开放权重（第三方核查）⚠️；官方文档亦只给 API 接入说明[27][28]。
10. **腾讯走开源路线。** HunyuanVideo 1.5（2025-11-21，8.3B，5–10 秒）已开源并接入元宝；HunyuanVideo 2.0 据第三方资料「已全面开源」，但官方发布日期本报告未独立核实 ⚠️。腾讯的闭源商用主要走「元宝 C 端＋腾讯云生视频 API」[48][49][50]。
11. **新变量：Vidu Q4 Preview。** 生数科技 2026-10-08 发布 Q4 Preview，最多 15 张参考图＋3 段参考音频，支持 2K/4K，首发优惠 0.09 元/秒起，是目前国内公开报价最低的旗舰档之一[39]。
12. **中国模型的差异化不在「参数」而在「工作流」。** 即梦×剪映×抖音、可灵×快手内容生态、万相×阿里云/百炼、混元×元宝，构成「模型—工具—分发」闭环；这也解释了为何 AA Elo 相近的模型在商业表现上差距巨大。

## 2 各厂商分节

### 2.1 快手 · 可灵 Kling（闭源，商业化最成熟）

**版本时间线**
- **可灵 3.0 系列**：2026-02-05 全球上线（科技日报、科普中国均报道），面向黑金会员首发；主打 All-in-One 全模态（文本、图像、音频、视频原生输入输出，把视频理解、生成、编辑整合进一条工作流），支持**最长 15 秒连续生成**，引入**智能分镜与自定义镜头控制**（[5][6][19][75][76]）。
- **可灵 3.0 Omni 1080P Pro**：据百度百科词条，2026-01-31 随 3.0 系列内测、02-05 正式上线并先向黑金会员开放；⚠️ 该日期来自百科二次来源，官方口径为「2 月 5 日上线 3.0 系列」[5][6]。
- **可灵 4.0**：2026-10-15 正式上线（快手 IR 新闻稿 10-17 发布）。官方三大突破：① 高动态/强运镜稳定性提升；② **单次原生生成最长 30 秒**，支持长镜头与连续叙事；③ **全能参考最多 15 项素材**（图片≤10、视频≤5、主体≤7）＋**最多 10 张关键帧**；支持最高 10bit HDR 输出；已提供 1080P，官方称将支持 4K 与 21:9 超宽画幅；提示词上限 8000 tokens；续拍「后续支持多次续拍，最长延展至 2 分钟」；已接入可灵 MCP 与 CLI，**API「即将」开放**（[1][4][9][82]）。
- 截至 2026-11-03，**未检索到「Kling 5.0」或更晚版本**；「Kling 4.0」即最新旗舰。

**能力要点（4.0）**：文生/图生/首尾帧/关键帧生视频；参考生视频（参考主体图、三视图、宫格图、故事板、线框图；参考视频中的表演、动作、运镜、叙事节奏；白模视频、深度图视频亦可作参考）；原生音频（音色参考）；动作控制（3.0 时代已有 Motion Control 计费项）；多镜头（导演思维对提示词做扩展，推拉摇移跟拍环绕）。
**短板（第三方实测暴露）**：长镜头下的「零真人出镜手搓探展」测试显示，大部分环境声与口播可直接用，但复杂叙事仍需人工拼接与筛选（钛媒体 2026-11-01）[9]。

**C 端与商业化**
- 入口：可灵AI App、网页端（klingai.com），国内/国际双版本。
- 会员（国内，2026-11 抓取）：黄金 ¥66/月·660 灵感值；铂金 ¥266/月·3000；钻石 ¥666/月·8000；黑金 ¥1319/月·26000；单独购买灵感值约 ¥6.97/100（[8]，档位价格以官网为准）。官网会员页显示「Kling 4.0 限时 9 折，720P 带视频参考低至 0.33 元/秒」。
- 商业化数据：2026Q1 营收 >6.5 亿元（同比 +300%）；2026-03 ARR 近 5 亿美元（2025-03 为 1 亿美元）；截至 2026-06 全球用户破 1 亿（2025 年底 6000 万）、企业客户近 5 万家（2025 年底 3 万家）、覆盖 224 个国家和地区；累计生成超 6 亿条视频、服务超 6000 万创作者（[2][3][19]）。
- 融资：2026-07 快手公告完成首轮独立融资，外部增资上限 30 亿美元，投后估值 180 亿美元，腾讯、阿里、百度罕见同台入局，融资后快手持股 68.33%；实际到账增资款约 198.02 亿元人民币（约 29.05 亿美元），高盛、瑞银担任港股 IPO 承销商，公司明确 **2031 年前 IPO** 时间表（[10][11][19]）。⚠️另有媒体称「维持 2027 年初港股 IPO 目标」（2026-07 报道），与 2031 年口径并存，以官方公告为准[12]。
- ⚠️「2025 全年＋2026Q1 累亏超 20 亿元、预计 2028Q4 单季盈亏平衡」为项目内 Lead 核实笔记引述新华网/凤凰网报道，本报告未独立复核。

### 2.2 字节跳动 · Seedance / 即梦 Dreamina / 豆包 / 火山方舟

### 2.3 MiniMax · 海螺 Hailuo H3 / H3 Max（半开源）

**H3（2026-07-31 发布）**：通用型全模态生成系统，统一理解文本、图像、视频、音频上下文，输出**最高 2K、最长 15 秒、带原生立体声音频**的视频。官方规格：输出 4–15 秒；宽高比 21:9/16:9/4:3/1:1/3:4/9:16；默认短边 768P（H3-Regenerate-2K 可出 2K）；**24fps**；**32kHz 立体声**；稳定支持 11 种语言。输入：首尾帧模式（0/1/2 张图）；全模态参考模式（图≤9、视频≤3 段共≤15s、音频≤3 段共≤15s，混合输入合计≤12 个）。系统由 H3-Context-IR、H3-Base、H3-Regenerate-2K 三模块组成（[32][33]）。
**开源边界（关键核实）**：官方开源的是 **H3-Base 的两个任务 checkpoint：H3-Base-FL2VA 与 H3-Base-Ref2VA**（HF + 魔搭，SGLang/vLLM/diffusers/ComfyUI 可部署），**H3-Context-IR 与 H3-Regenerate-2K 明确未开源**，2K 完整链路需调用官方 API；许可证为《MiniMax H3 Community License》。架构：33B dense single-stream Omni-Transformer（约 13B 在 AdaLN 分支，纯推理可不加载），文本编码器采用 Qwen3-VL-32B 第 50 层 hidden states；稀疏注意力首个开源版未提供（[32]）。因此 **AA 页面「open weights 领先」的说法成立，但只对 H3-Base 成立，不等于整套系统开源**（[70]）。据项目内 Lead 核实笔记：开源一个月 HF 下载 >2400 万次、300+ 衍生模型，许可协议约定商用年收入 >2000 万美元需书面授权 ⚠️。
**H3 Max（2026-08 底—09-01 ⚠️）**：更快、更便宜的版本，5–15 秒，480P/768P，**无 2K**；第三方资料称其基于 H3（fal 后训练）[34][35]。
**定价**：H3 API 约 **$0.08/秒（768P）、$0.05/秒（480P）**，2K 约 **$0.101/秒**（海螺订阅页测算）[36]；AA 折算 H3（768p）**$4.80/分钟**、H3 Max **$9.60/分钟**[70]。⚠️ AA 的 H3 Max 单价与第三方 $0.08/秒 口径不一致，可能因基准分辨率不同。
**海螺AI**：hailuoai.com 与 App；国内会员 **¥65（基础）/¥243（标准）/¥1,399（尊享）每月**，基础年费 ¥619（App Store 分档）[86]；国际站 Standard $14.99 等档[36]。
**商业化**：MiniMax 2026 上半年营收 **4,264 万美元（+100.9%）**，年化约 53 亿元；B 端收入占比升至约六成，海螺AI 及其他 AI 原生产品营收占比约 36.6%（[37]）。

## 5 竞争格局与趋势

1. **四强地位确立但排序不稳。** 阿里靠 Wan 3.0（T2V/编辑双榜第一）＋HappyHorse（性价比 API）双线；字节靠 Seedance 2.5（I2V 第一、编辑第二）与即梦/剪映/抖音生态；快手靠可灵 4.0 的专业影像定位与最快商业化；MiniMax 靠 H3 的半开源＋高性价比 API 抢占开发者。四家在不同榜单互有胜负。
2. **开源成为「获客＋生态」武器。** MiniMax 开源 H3-Base、Sand.ai 开源 MAGI-2，直接催生 Hyperflow H3、Pika H3 Flex、英伟达 Open-H3-Regenerate-2K 等衍生（Lead 核实笔记）；闭源的阿里 Wan 3.0 则用「托管 API＋低价」守住份额。两种路线在 2026H2 首次正面碰撞。
3. **价格战的底部由算力成本决定。** 业界普遍认为 0.5 元/秒已接近成本红线（DoNews 分析）；即梦因 Seedance 2.0 排队 8–10 小时而涨价、可灵/阿里趁机降价接盘，形成「C 端涨价、B 端降价」的分裂格局[19]。
4. **C 端竞争将从「抽卡」转向「工作流」。** 可灵 All-in-One、即梦短剧工作室、MiniMax Design、剪映 Agent、万兴剧厂都在把模型嵌进「脚本—分镜—生成—剪辑—分发」链条；单纯比 Elo 的时代正在结束（推测）。
5. **合规与版权成为隐性门槛。** Seedance 官方明确「真人人像主体参考须本人验证或授权」[13]；H3 对输入与增强 Prompt 做自动内容审核[32]；国内深度合成备案与 AI 标识要求将影响 C 端功能开放节奏（推测）。
6. **风险**：Sora 于 2026 年关停（Lead 核实笔记）说明「通用视频模型」商业化艰难；中国厂商虽在榜单与价格上领先，但盈利压力大（可灵累亏、MiniMax B 端依赖上升），2027 年前后或出现整合。
