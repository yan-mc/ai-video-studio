### 5.1.2 国内平台的三条竞争逻辑

1. **生态闭环决定留存**：即梦×剪映×抖音（创作—剪辑—分发）、可灵×快手内容生态、万相×阿里云/百炼、混元×元宝/微信。**模型质量相近时，谁离分发更近谁赢。**
2. **C 端涨价、B 端降价**：即梦 2026-03 调价（15 秒 45→120 积分，成本约 2.6 倍）引发投诉后部分回调；同期火山方舟 Seedance 2.0 Mini 约 0.5 元/秒、可灵与阿里降价接盘。平台在用价格筛用户、把算力留给高价值场景。
3. **工具向"短剧/成片"演进**：即梦"短剧工作室+3D 导演台"、剪映 Hub/剪映助手、小云雀 Agent（一键解析最多 10 万字剧本）、万兴剧厂、MiniMax Design——从"生成按钮"变成"替你干活的员工"。

## 5.2 海外 C 端平台：Sora 退场后的多极格局

### 5.2.1 Sora：从现象级爆款到停服（本章重点）

- **上线**：2025-09-30 Sora 2 + Sora App（美加邀请制）；Appfigures 数据显示上线头两天下载 **16.4 万次**；TikTok 式信息流 + cameo（人脸/声音授权客串）+ remix，被媒体称为"AI 版 TikTok"。
- **争议**：2025-10 因 Bryan Cranston/SAG-AFTRA 施压，OpenAI 为 cameo 增加"本人显式 opt-in"机制。
- **停服（官方确认）**：Sora 网页/App **2026-04-26 停止服务**；Sora API **2026-09-24 停止服务**。
- **成本**：SemiAnalysis 测算日均运行成本约 **1,500 万美元**、年化约 **54 亿美元**；可用率仅 5%—10%——"免费/低价 + 高分辨率 + 原生音频"的单位经济模型不成立。
- **重启传闻**：2026-10 报道 OpenAI 正洽谈把 Sora 业务/技术授权给由 **Jeffrey Katzenberg（梦工场联合创始人）+ Bill Peebles（Sora 前研究负责人）+ Sujay Jaswa（前 Dropbox CFO）** 创立的新公司，转向专业影视工具；**截至 2026-11 未官宣成交**，C 端无可用入口与订阅价 ⚠️。
- **历史权益（供参考）**：ChatGPT Plus 最高 480p/10 秒、Pro 最高 1080p/20 秒 ⚠️ 历史口径。

> **Sora 的教训**：C 端 AI 视频的"社交化"需要极低边际成本与极高留存，而 2026 年的推理成本结构两者都不满足。**未来 C 端视频产品更可能是"工具+订阅+成片服务"，而不是"信息流+免费+广告"。**

### 5.2.3 海外平台的三条主线

1. **Google 的"生态+订阅"路线**：Veo 3.1 + Gemini Omni + Flow + YouTube/Shorts 分发 + AI Plus/Pro/Ultra 订阅，是唯一覆盖"模型—工具—分发—订阅"全链路的海外玩家；但 Veo 3.1 质量榜落后（AA 961 分/第 22），靠 Gemini Omni 的编辑能力与生态补位。
2. **"聚合+分发"路线崛起**：Pika API Club（100+ 模型）、Krea、Higgsfield、Freepik、Canva、Runway 上架第三方模型——**模型商品化后，渠道与工作流成为估值锚点**。Higgsfield 估值 54 亿美元、Krea 5 亿美元、Runway 30—53 亿美元，均体现"分发溢价"。
3. **数字人/口播独立赛道**：HeyGen（ARR 2 亿美元）、Synthesia（40 亿美元估值）、Hedra、D-ID、Captions——不追求"生成电影"，但付费意愿强、场景稳定（培训、电商、多语言出海）。

## 5.3 定价机制：四个共同趋势

1. **积分/灵感值是 C 端主流**，且"档位越高→每积分单价越低"（可灵 100 灵感值单价 6.97→3.52 元；Runway/Pika/Higgsfield 同理）。积分制的本质是"预付费 + 价格歧视 + 锁定留存"。
2. **按秒计费成为 API 与专业工具的默认口径**（海螺 $0.08—0.13/秒、通义万相 0.6—1 元/秒、Higgsfield 按模型秒价、可灵 API 按秒）。按秒让成本可预测，也便于比价。
3. **商用授权绑定付费档位**（Pika Pro 才含商用、可灵黄金及以上可商用、H3/LTX/混元等开源许可另有条款）——**"能不能商用"比"多少钱"更影响 B 端选择**。
4. **"免费"正在收缩为限时/限量**：Sora 从"免费+宽松额度"到关停；Midjourney 全程无免费档；Canva 免费视频生成仅 5 次（终身）；平台普遍用"每日签到积分"替代"免费额度"。

| 文旅宣传 | 地方政府、景区、文旅企业 | 文案→实景素材+AI 生成→配音→成片 | 洛神 AI 类工具、即梦、可灵、Vidu | 从数万—十万元降至几千—1 万元，周期数天 |
| 游戏素材 | 游戏买量团队、独立开发者 | 角色/场景设定→动态素材→投放测试 | Runway、Kling、Seedance、Pika | 素材迭代从周级到天级（⚠️缺公开量化） |
| 表情包/头像/壁纸 | 普通用户 | 一句话/一张图→图生视频/动图→社交分享 | 豆包、即梦、美图、Grok Imagine | 零边际成本，主要消耗免费额度 |
| 婚礼/纪念视频 | 家庭用户、婚庆公司 | 老照片→修复/动起来→配音→成片 | 即梦、可灵、Vidu、HeyGen 类 | 单条数百至数千元；情感类爆款案例多 |
| 数字人口播 | 知识博主、跨境卖家、企业 | 文稿/录音→数字人驱动→多语种→批量分发 | HeyGen、Synthesia、腾讯智影、硅基智能、闪剪、必剪 | 一条口播从拍摄+棚租降至分钟级；数字人月卡 300—1,000 元 |

**场景侧三个判断**：

1. **离钱最近的仍是"数字人+电商+广告"**：直接对应企业/商家的投放预算，付费意愿稳定；AI 短剧规模大但项目制、回款慢、亏损面高。
2. **"模板化/remix"是 C 端拉新最有效的手段**：Sora 的 cameo、PixVerse 的模板、剪映的一键成片，把"创作"降级为"选择+微调"，这是用户规模爆发的关键。
3. **工作流正在被 Agent 整合**：从"生成一个镜头"到"一句话→分镜→成片→多平台发布"，2026 年出现大量"短剧 Agent/内容智能体"（小云雀一键解析 10 万字剧本、智象 vivago R1 无限时长创作），C 端工具正从"功能按钮"变成"替你干活的员工"。

## 5.6 商业模式：C 端平台靠什么赚钱

| 模式 | 代表 | 特点 | 风险 |
|---|---|---|---|
| **订阅（SaaS）** | 即梦、可灵、Runway、HeyGen、Synthesia | 现金流稳定、可预测 | 免费额度收缩引发流失；价格战压缩毛利 |
| **积分/按次** | 即梦、可灵、Pika、Higgsfield | 价格歧视、锁定留存 | 用户比价、积分贬值感知 |
| **按秒 API** | 火山方舟、百炼、可灵 API、海螺 | 服务 B 端/开发者、可批量 | 价格战、算力成本刚性 |
| **成片/服务** | 即梦短剧工作室、万兴剧厂、MCN 代运营 | 客单价高、粘性强 | 人力密集、难以规模化 |
| **广告/分发分成** | 抖音/快手/TikTok、YouTube | 平台最大受益者 | 与 AI 内容治理冲突 |
| **生态/授权** | Adobe（Firefly+第三方模型）、Canva/Freepik、Runway 上架 Kling/Seedance | 渠道溢价、轻资产 | 依赖上游模型、同质化 |
