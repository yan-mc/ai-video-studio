# 9. 结论与建议

## 9.1 十条核心结论（最终版）

1. **行业阶段**：AI 视频 C 端制作已从"能不能生成"进入"能不能稳定、便宜、可编辑地做成一条能发布的片子"；模型能力不再是瓶颈，工作流、成本与合规才是。
2. **格局**：中国模型在质量榜全面上位（AA T2V 前十占五席、前五占三席，I2V 第一、编辑第一），国际阵营退守"生态/编辑/合规/影视垂直"；OpenAI 已实质退出。
3. **开源**：画质追到闭源前沿 1—3 名内（H3 与 Wan 3.0 仅差 12 Elo），但"可商用+低门槛"没追上；Wan 3.0 不再开源标志"半闭源化"；H3 成为商业模型的底座（fal/Pika/NVIDIA 衍生）。
4. **技术**：DiT + 高压缩 VAE 收敛；原生音视频、30 秒长镜头、多模态参考、编辑模型、少步蒸馏/实时化是 2026 年五大技术跃迁；通用大模型（Claude Opus 5.5/GPT-6 Astra）跨界构成非对称竞争。
5. **成本**：C 端单条 60 秒成片现金成本已降至 ¥70—250（云 API）/$50—200（专业 SaaS）；生成成本快速下降，但人工审片/返工占总工时 30%—50%，是新的瓶颈。
6. **平台**：国内"即梦 × 可灵"双寡头 + 多强跟随；海外 Google（Flow/Gemini）生态最全、Runway/Higgsfield/Krea 靠聚合与工作流、HeyGen/Synthesia 吃数字人红利；Sora 退场证明"社交化 AI 视频"模式暂不成立。
7. **场景**：离钱最近的是数字人+电商+广告；AI 短剧规模最大（400 亿元、6 亿用户）但 98.7% 不回本，"选题+投流"才是稀缺能力。
8. **商业**：C 端订阅年规模约 10 亿美元级（小池子），广告/电商/短剧的制作替代是千亿美元级（大池子）；行业"收入在涨、成本涨得更快"，算力自给与分发闭环决定长期胜负。
9. **合规**：中国 AI 标识强执行、欧盟 AI Act 第 50 条适用、美国州法拼图；AI 标识、肖像/声音授权、版权素材是三条红线，合规从成本项变成竞争壁垒。
10. **趋势**：2027 年 Agent 化、实时化、平台内置化、版权授权化、通用模型跨界五股力量叠加；基准情景是"工具门槛降低 + 专业工作流/合规溢价上升"。

## 9.2 对 C 端创作者：分人群行动建议

### 9.2.1 个人创作者/自由职业者

- **工具组合**：即梦会员（69 元/月）或可灵黄金（58 元/月）+ 剪映 SVIP + 免费 AI 音乐/配音；进阶加上海螺/Vidu 做质量提升。
- **能力建设**：把 70% 精力放在"选题、脚本、分镜、审片"；30% 放在"提示词/参考素材库"。**建立自己的角色/风格/场景库**，这是跨模型迁移的资产。
- **变现路径**：平台分成/商单/教程/模板；优先选择"平台内置 AI 工具"的渠道（抖音/快手/视频号），降低获客成本。
- **合规**：发布勾选 AI 标签；不用明星脸/声音；BGM 用平台曲库。

### 9.2.2 中小团队/MCN

- **工具组合**：火山方舟/百炼/可灵 API（按秒、失败不计费）+ 剪映/CapCut + Runway Aleph/Kling Omni 做精修 + HeyGen/Hedra 做口播。
- **流程**：建立"脚本—分镜—生成—审片—编辑—投放"的 SOP，把"2 倍重试、1—3 轮局部修改"写进排期；用内部基准（任务成功率、单条成本、人评）替代"看榜单选模型"。
- **成本**：60 秒成片目标成本 ¥70—250（云 API 档）；批量内容优先用 0.2—0.5 元/秒档模型，重点镜头用高端档。
- **合规**：建立 AI 资产台账与授权文件；数字人主播持续提示 AI 身份。

### 9.2.3 商家/电商/广告主

- **工具组合**：即梦/火山方舟（Seedance 2.0 Mini）+ 秒创/Higgsfield（商品模板）+ HeyGen/Creatify（UGC 广告）+ 剪映。
- **重点**：商品细节一致性（包装/logo/文字）与多 SKU 批量；单条广告成本可降到 1—10 美元，但需 A/B 测试与投流能力配合。
- **合规**：AI 模特/换装注意肖像权与消费者知情权；带货视频标注"广告"与"AI 生成"。

### 9.2.4 AI 短剧/动漫团队

- **工具组合**：即梦短剧工作室 + 可灵 4.0（30 秒/续拍 2 分钟）+ Vidu Q4（高性价比/2K-4K）+ 配音/口型工具 + 投流。
- **现实**：98.7% 项目不回本，进入前先算"投流 ROI"；优先做"能稳定产出爆款"的头部工作室，或转向"代运营/投流服务"。
- **趋势**：精品化 + 投流能力 + IP 授权是 2027 年的分水岭。

## 9.3 对开发者/创业者

- **不做"又一个生成按钮"**：模型商品化 + 平台内置化会挤压纯工具；机会在"垂直工作流（短剧/电商/教育/本地生活）+ 一致性资产（角色/场景/声音库）+ 合规能力"。
- **技术选型**：快速验证用闭源 API（火山方舟/百炼/可灵/Gemini）；成本敏感/私有化用开源（Wan 2.2 Apache-2.0、H3 非美欧英韩、LTX-2.5 <$1,000 万营收）；注意许可证。
- **产品形态**：Agent 成片工作台、批量化工具、IP 授权素材库、AI 标识/合规中间件、跨境多语言数字人。
- **商业模式**：按成片/任务收费优于按次；与企业/平台分成优于纯订阅。

## 9.4 对投资者/企业采购

- **投资**：优先"算力自给+分发闭环"（字节/快手/阿里/Google 生态）与"聚合+工作流"（Higgsfield/Krea/Runway）两类；警惕"只有模型、没有工作流与收入"的标的；关注并购整合机会。
- **企业采购**：按"任务成功率+单条成本+合规"评估，而非只看榜单；优先选择有商用授权/赔偿条款的供应商；建立内部 AI 视频基准与资产台账；与 2—3 家供应商保持合作以对冲价格与技术变化。
- **自建 vs 采购**：年生成量小/合规要求高→云 API + 私有化部署开源（Wan 2.2/H3）；年生成量大/数据敏感→自建推理集群 + 微调；不建议在 GPU 溢价 370% 时自购旗舰卡。

## 9.5 30 天 / 90 天 / 半年行动清单

| 周期 | 个人创作者 | 团队/商家 |
|---|---|---|
| **30 天** | 选 1 个主平台（即梦/可灵）+ 剪映，跑通 5 条成片；建立提示词/参考图库；完成 AI 标识与版权自查 | 确定 2—3 个模型组合与预算；跑通 1 条业务线（电商/广告/口播）；建立成本台账 |
| **90 天** | 形成稳定更新节奏；测试 1—2 个新模型（海螺/Vidu/Google Flow）；尝试商单/分成变现 | 建立 SOP 与内部基准；接入 API 批量生产；完成合规流程（标识/授权/数字人提示） |
| **半年** | 建立个人风格/角色资产；探索多平台分发与出海 | 评估自建 vs 采购；布局 Agent 工作流；跟踪政策与平台规则变化 |

## 9.6 结语

2026 年的 AI 视频行业像一个"能力过剩、交付稀缺"的市场：模型每个月都在变强、价格每个季度都在下降，但真正能稳定产出"可发布、可商用、可投流"内容的团队仍然是少数。**决定胜负的不再是"你用了哪个模型"，而是"你有没有把模型嵌进一条可重复、可核算、可合规的生产线"。**

对 C 端创作者而言，这是最好的时代——工具成本从未如此之低；也是最需要判断力的时代——因为"会生成"正在变得免费，"会选择、会审片、会投流、会合规"才是新的护城河。

## 附录 F 调研方法与局限

**方法**：
1. 5 个方向并行检索（国际闭源/国内闭源/开源/技术工具/平台市场），每个方向 20+ 轮中英文搜索、官方页面与榜单二次抓取；
2. 所有关键数据（发布时间、规格、价格、榜单、用户数、融资）标注来源与日期；
3. Lead 独立核验 AA 三张榜单、OpenAI 帮助中心、Kuaishou IR、Anthropic/OpenAI 发布页等一手来源；
4. 对冲突数据（发布日期、价格口径、Elo 版本）做标注与取舍，保留 ⚠️ 项。

**局限**：
- 闭源产品无法实测，榜单 Elo/厂商宣称/媒体评测为主要依据；
- 价格与榜单每日变动，报告为 2026-11-03 快照；
- 部分厂商不披露参数/训练数据/真实用户数，存在信息不对称；
- 市场规模存在多套口径，报告并列呈现、不强行统一；
- 趋势判断包含推测成分，已标注证据强度。

**更新建议**：建议每季度更新一次榜单、价格与产品功能；每月跟踪合规政策与平台规则；每半年复核市场规模与融资数据。
