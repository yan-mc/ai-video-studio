# 0. 调研说明：范围、口径与方法

## 0.1 为什么是"C 端制作"

本报告的"AI 视频 C 端制作"，指**个人创作者、中小团队、商家与内容机构**（而非影视工业级管线或纯 API 开发者）使用 AI 工具完成一条可发布视频的全过程，包括：选题脚本 → 分镜/参考素材 → 视频生成 → 编辑重绘 → 配音/音效/口型 → 超分/补帧 → 剪辑/字幕 → 多平台分发。

选择"C 端"作为切口，是因为 2026 年行业出现了一个关键转折：**B 端（影视/广告/电商）愿意为"可控、可预算、可审核"付费，而 C 端（个人/小团队）愿意为"快、便宜、能发布"付费。** 这两类需求正在把同一批模型能力拆成不同的产品形态——本报告重点回答后者。

## 0.2 时间基准与"最新"的定义

- 报告定稿与数据抓取：**2026 年 11 月 3 日（北京时间）**。
- "最新"指：以 2026 年发布/更新的信息为主，必要时回溯至 2024 年（Sora 技术报告、VBench 发布等）。
- 视频模型迭代以"月"为单位，报告中所有模型均标注**版本号 + 发布时间**；榜单数据标注**抓取时点**。

## 0.3 口径与分级

报告中所有事实按可信度分级标注：

| 标记 | 含义 |
|---|---|
| （无标记） | 官方页面、官方博客、模型卡、定价页、监管原文等一手信息 |
| `[第三方]` / `媒体口径` | 权威媒体、研究机构、第三方评测（如 Artificial Analysis、Sensor Tower、QuestMobile） |
| `⚠️` | 未能交叉核实、来源单一或存在冲突，引用需谨慎 |
| `推测` / `判断` | 本报告基于证据的分析结论，非事实陈述 |

**三个必须注意的口径问题**：

1. **AA Elo 不可跨版本比较**：Artificial Analysis 于 2026-09 重构视频榜（拆分带音频/静音、新增编辑榜、更换锚点）。2026 年 4 月媒体称 HappyHorse-1.0 达 1378 分，现版（v2.1）仅 1033 分——不是模型变差，而是量表变了。本报告只做"同一抓取时点的相对位次"比较。
2. **AA 的 $/分钟 ≠ 国内刊例价**：AA 按"1080p 基准 + 固定评测参数"把 API 价格折算为每分钟成本；中国厂商国内按元/秒报价，档位、分辨率、是否带音频差异很大，两者不可直接混用。
3. **市场规模至少三套口径**：软件/订阅市场约 10 亿美元级、模型产业收入约 77 亿美元级、C 端创作者付费约 1% 渗透率——结论取决于统计边界，引用时必须注明。

## 0.4 方法与流程

本报告采用"多智能体并行调研 + Lead 交叉核验"的方式完成：

1. **分方向检索**：5 个方向（国际闭源模型 / 国内闭源模型 / 开源模型 / 技术与工具 / 平台与市场）分别进行 20+ 轮中英文检索，对官方页面、模型卡、定价页、AA 榜单、监管原文做二次抓取。
2. **结构化沉淀**：每个方向产出 6,000—9,000 字的原始研究，含编号来源（合计 400+ 条链接）与"信息缺口/待核实"清单。
3. **交叉核验与纠偏**：Lead 独立抓取 AA 三张榜单、OpenAI 帮助中心、Kuaishou IR、Anthropic/OpenAI 发布页等一手信息，对冲突数据（如 Seedance 2.5 发布日期、GPT-6 Astra 日期、HeyGen 常规价）进行标注与取舍。
4. **汇总撰写**：按"行业—技术—模型—工具—平台—市场—合规—趋势—建议"九章结构重组，所有关键数字回归原始来源。

## 0.5 主要局限

- **付费/闭源产品无法实测**：榜单 Elo、厂商宣称、媒体评测是主要依据；同一模型在不同平台/参数下的表现可能差异很大。
- **价格变动极快**：促销价、积分制、区域定价频繁调整，报告价格仅为 2026-11 时点快照。
- **信息不对称**：部分厂商不披露模型参数、训练数据与真实用户数；本报告已尽量用第三方数据交叉，但仍存在 ⚠️ 项。
- **中文/英文信息偏差**：中国厂商的中文发布信息更全，海外厂商的英文文档更全；两者在"发布时间"上常有一周到数月的口径差（如 AA 的 "Released" 与厂商首发日不同）。
