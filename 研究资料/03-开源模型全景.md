## 0. 摘要与关键结论

### 0.1 五条主结论

1. **2026 年开源阵营的"质量天花板"已经追到闭源前沿的 1–3 个名次之内，但只限"开放权重、且有区域许可限制"的那一两个模型。** AA 文生视频（含音频）榜上，开放权重最佳的 MiniMax H3 为 1160 Elo，闭源第一 Wan 3.0 为 1172 Elo，仅差 12 分（约 52% 胜率）[27]；但若按"可直接商用、无区域限制"筛选，最佳开源就掉到 MAGI-2（1041）与 LTX-2.5（940–944）档位，与前沿差距拉大到 120–230 Elo。
2. **开源的真实领跑者是 MiniMax H3（2026-07-31 发布、2026-08-03 开放权重），而不是 Wan。** H3（33B 单流 Omni Transformer、原生 32kHz 立体声、4–15 秒、最高 2K）在 AA "Silent（无音频）"榜是开放权重第一（T2V 1120 / I2V 1110），含音频 I2V 榜第 4（1131）；其社区蒸馏版 Hyperflow H3 更把开放权重 I2V-Silent 推到 1118、视频编辑榜第 3（1151）[27][28][29][30]。开源一月 HF 下载 2400 万+、公开衍生模型 300+[14]。
3. **Wan 系列已"半闭源化"：Wan 2.1（2025-02）与 Wan 2.2（2025-07）仍是最干净、生态最大的 Apache-2.0 资产，但 Wan 2.5/2.6/2.7/3.0 全部只走托管 API。** 尤其 Wan 3.0（2026-08-24 发布）截至 2026-10-16 无权重、无模型卡、无代码，属纯托管模型[6]；它在 AA T2V（1172，第 1）、视频编辑（1196，第 1）两个榜上都是当前最强闭源/托管模型——"最强 Wan"不再开源，是本报告最重要的行业信号。
4. **消费级可跑的开源模型，落后前沿约"一整代"。** 单张 24GB 卡能确定性跑通的仍是 Wan 2.2 TI2V-5B（720p/24fps、5 秒 <9 分钟，官方口径）与 LTX-2.5（官方最低 16GB）；它们在 AA I2V 只有 913–917 Elo，比闭源第一（Seedance 2.5，1157）低约 240 分——即"能本地跑"与"能打前沿"是两条产品线。
5. **开源生态的瓶颈已从"模型能不能出片"转为"许可能不能商用 + 显存够不够"。** 纯 Apache/MIT 可自由商用的第一梯队只有 Wan 2.1/2.2、MAGI-2、Kandinsky 5.0、Step-Video、Mochi 1、Open-Sora 2.0；而质量更高的 H3、HunyuanVideo 1.5、LTX-2.x、SkyReels、CogVideoX-5B 都带区域/营收/用途附加条款（详见第 6 节表 4）。

## 2. 第一梯队模型详解

### 2.1 MiniMax H3：2026 年开源生态的"现象级"事件

- **发布节奏**：2026-07-31 发布 H3 通用多模态生成模型；**2026-08-03 在 Hugging Face 放出核心权重**（"社区许可"），同日 ComfyUI 原生支持落地[13]。官方口径 4–15 秒、最高 2K、原生 32kHz 立体声音频；`Ref2VA` 变体支持最多 9 张图、3 段视频、3 段音频作为参考输入，`FL2VA` 支持首尾帧[18]。
- **架构**：33B 参数单流 "H3-Omni" Transformer 联合预测视频与音频（约 13B 参数分布在 AdaLN 分支，纯生成可跳过）[30][33]。
- **榜单**：AA 文生视频（含音频）1160 Elo 第 3，是开放权重第一；图生视频 1131 Elo 第 4；视频编辑 1123 Elo 第 5（2026-08 曾登顶编辑榜，此后被 Wan 3.0/Seedance 2.5 反超）[27][28][29]。**"AA 称其 leads among open weights"经核实成立**——更准确地说是在"无音频（Silent）"分榜与含音频榜上均为开放权重第一[27][28]。
- **生态爆发**：开放一个月 HF 下载 2400 万+、公开衍生模型 300+[14]；截至 2026-11-03 主仓 30 天下载仍有 **634 万**、likes 6,537。衍生方向包括：fal 训练的闭源 **H3 Max**（AA T2V 1148、I2V 1118）、Pika 2026-10-29 发布的闭源 **H3 Flex**（宣称比 H3 Max 快 1.8×、便宜最多 80%）[16]、NVIDIA/MIT 的 2K/4K 重生成、以及社区蒸馏 **Hyperflow H3**（AA 开放权重 I2V-Silent 第一 1118）[15][17]。
- **许可雷区（必须写进报告）**：MiniMax H3 Community License 将**美国、欧盟、英国、韩国排除在"适用领土"之外**——这些地区的公司/个人不能本地部署权重（可申请单独许可），通过 MiniMax 全球 API 使用则不受此限；年收入 >2000 万美元需书面授权，且产品 UI 需标注 "MiniMax H3"[30]。
- **部署**：官方文档给 SGLang/vLLM 多卡本地部署示例（如 8 GPU）；官方未给最低显存。社区 NVFP4 量化（DiT 约 12GB）配 CPU offload 文本编码器可上 32GB 的 RTX 5090[19]；2026-09 起 ComfyUI 侧有 Hyperflow int8 节点与 PowerShard 多卡 FSDP2 插件。

### 2.2 Wan 2.1 / Wan 2.2：Apache-2.0 生态的基本盘，但"最强 Wan"已闭源

- **Wan 2.1（2025-02-25）**：14B 与 1.3B 两个规格、推理代码与权重全量放开，**Apache-2.0**；1.3B 在 8.19GB 显存即可生成 5s 480p（RTX 4090 约 4 分钟），14B 主打质量[2][5]。GitHub 17,366★，HF 上 T2V-14B 近 30 天下载 10.4 万——仍是下载量最大的开源视频权重之一。
- **Wan 2.2（2025-07-28）**：A14B 采用 MoE（高噪声/低噪声双专家，总 27B、每步激活 14B），TI2V-5B 用 16×16×4 高压缩 VAE 统一文/图生视频，**720p@24fps，单卡 24GB（RTX 4090）5 秒 <9 分钟**，官方称其为"最快 720p@24fps 开源模型"之一；14B 单卡需 80GB，多卡用 FSDP+Ulysses[1][5]。后续同许可证扩展出 **S2V-14B（2025-08-26，音频驱动）**与 **Animate-2-14B（2026-08-07，角色动画/替换，含蒸馏版）**[8]。
- **生态**：ComfyUI 原生（2.1 于 2025-02、2.2 于 2025-07-28 当天）、Diffusers 官方集成、社区量化（GGUF Q2–Q8、FP8、LightX2V 步数蒸馏、Cache-dit 加速、WanVideoWrapper）；VBench 总分开源第一约 84.7（Wan 2.2）/83.1（Wan 2.1）[31]。
- **关键信号**：Wan 2.5（2025-09-24，首次带原生音频、10s、1080p）开始只做闭源 API；此后 Wan 2.6（2025-12–2026-01）、Wan 2.7（2026 年 Q2）、**Wan 3.0（2026-08-24）**均无权重。第三方在 2026-10-16 核查 Wan 3.0：无 Hugging Face 仓库、无 model card、无代码，仅阿里云 Model Studio 托管[6]。**"Wan 开源"应限定为 "Wan 2.1/2.2 开源"，不能外推。**

### 2.3 LTX-2 / LTX-2.5：开源阵营的"速度+音频+专业交付"路线

- **LTX-2（2025-10-23 发布，权重 2026-01 上线，19B）**：音视频一体生成，支持 4K 原生能力、最高 50fps、20s 时长；2026-01 曾以 1,198/1,195 Elo 位居 AA 开放权重第一（当时刻度）[25]。HF 仓库 2026-01-03 创建、近 30 天仍 30.4 万下载[10]。
- **LTX-2.3（2026-03）**：22B，速度优化版，AA T2V 884（Pro）/839（Fast）。
- **LTX-2.5（2026-08-11 发布；HF 仓库 2026-07-23）**：22B Transformer + Gemma 4 12B 文本编码器；Diffusion Fidelity Rendering（8× 时间压缩潜空间 + 关键帧锚定）、原生多镜头、48kHz 同步音频、HDR ACES、自动时长预测。官方宣称：10s 720p 图生视频在 **2×NVIDIA GB200 上 6.8 秒**、API 1080p 23.7 秒；官方最低 **16GB 显存**；ComfyUI 首日原生集成[20][21]。**注意：以上速度为厂商自报，截至 2026-11 无独立复现**。
- **榜单现实**：LTX-2.5 Fast/Pro 在 AA T2V 仅 944/940（#25/26）、I2V 917/913（#25/26），说明其定位是"开放权重里最快、带音频、能在 ComfyUI 里跑"，而非画质最强[27][28]。
- **许可**：LTX-2.x Community License——年营收 <1000 万美元的组织免费（含商用），超出或被用于竞品/转售需付费商业许可；权重下载需登录接受条款[22][23][30]。

### 2.4 HunyuanVideo 1.5：消费级 8.3B 的"轻旗舰"

- 2025-11-20 发布推理代码与权重，**8.3B DiT + 3D 因果 VAE（16×16×4）+ SSTA 稀疏注意力**；支持 480p/720p T2V/I2V、121–241 帧（5–10s），内置 720p→1080p 少步超分网络；官方最低 **14GB 显存**（开 offload），8×H800 上 720p/121 帧约 28.3s（50 步）[9][12]。
- 工程化迭代很快：2025-11-24 ComfyUI 原生、11-27 缓存推理（deepcache/teacache/taylorcache）、12-05 **步数蒸馏模型**（480p I2V 8/12 步，RTX 4090 提速约 75%，单卡 75 秒出片）+ 训练/LoRA 代码、12-23 FP8 GEMM；Diffusers 官方集成[9][11]。
- 口碑：GSB 人工评测中 720p T2V 对 Wan2.2 胜率 +11.02%、对 Veo3 +17.12%（**厂商评测，非独立**）[9]；GitHub 4,591★、HF 主仓 1,059 likes。
- **许可**：Tencent Hunyuan Community License，含领土限制（不含欧盟/英国/韩国）与使用限制，商用需遵守条款[10]。
- **后续版本**：截至 2026-11-03 **未检索到 HunyuanVideo 2.0 的官方开放权重/仓库**；腾讯 2026 年的视频侧动作更多在托管 API（混元生视频旧接口 2026-09 起分批下线、统一到 TokenHub 控制台）[46]。⚠️ 若有 2.0 开源计划，需在 2026-12 后再核。

### 2.5 MAGI-2 Preview：许可最干净、门槛最高的"千亿 MoE"

- 2026-08-05 发布，**114B 总参数、单次前向仅激活约 6B**，全球首个千亿级开源 MoE 视频模型；10s、1080p，支持时间轴 JSON prompt；**Apache-2.0，无营收/区域门槛**，是"第一梯队 + 纯商用许可"的唯一组合[30][32][33]。
- 代价是硬件：约 307GB 权重，官方要求 **8×H100/H200（80GB）**，1080p 两阶段无法在单张 80GB 内共存；AA T2V 1041（#15）、2026-10 时 I2V 1093（#10）；**不支持 ComfyUI**，无官方 API[27][30]。
- 成本口径分歧极大：媒体称 8×H100 下 10s 1080p 约 0.5 元（边际算力口径）[32]；第三方对 AWS 租用的估算为 25–42 美元/10s[30]。两者不可直接混用，⚠️ 需按自有卡折旧或云报价重算。

### 5.2 推理速度（口径混杂，务必在报告中标注来源）

- **Wan2.2-TI2V-5B**：5s 720p <9 分钟（官方，单张消费级卡）[1]。
- **HunyuanVideo 1.5**：480p 约 75s/条（第三方汇总，4090）[31]；8×H800 上 720p/121 帧 28.33s（官方，50 步）[9]；步数蒸馏后 4090 单卡 75 秒级（官方）[9]。
- **LTX-2.5**：10s 720p I2V 6.8s（2×GB200，**厂商宣称**）；API 1080p 23.7s（厂商宣称）[20]。
- **H3**：官方 API 768p $4.80/分钟、2K 0.8 元/秒；本地速度取决于卡数与是否用 Hyperflow（社区称 few-step 后显著加速 ⚠️）[13][14]。
- **MAGI-2**：10s 1080p 边际成本约 0.5 元（媒体）、AWS 估算 25–42 美元/10s（第三方）——两个口径差异巨大，⚠️不可直接引用[30][32]。
- **消费级经验值**（社区汇总，非官方）：24GB 卡跑 Wan2.2-5B 720p 5s 约 7–10 分钟；LTX-2.5 720p 10s 在 24GB 卡上约数分钟级（取决于步数与量化）⚠️。

### 5.3 量化与加速生态

- **GGUF**：ComfyUI-GGUF（4,225★）是事实标准；Wan2.1/2.2、SkyReels、LTX-Video、H3（社区 Q2_K–Q3_K_M）均有现成 GGUF；8–12GB 卡主要靠这条路。
- **FP8**：Wan2.2 官方生态（LightX2V/DiffSynth-Studio）、HunyuanVideo 1.5 FP8 GEMM、LTX-2.5 官方 FP8 + CPU offload。
- **int8 / NVFP4**：LTX-2.5 官方提供 int8 与 Blackwell NVFP4 权重；H3 社区 NVFP4（DiT 约 12GB）。
- **步数蒸馏**：HunyuanVideo 1.5 step-distill（8/12 步）、Wan LightX2V、H3 的 Hyperflow、LTX-2.5 少步（官方 8 步级）。

### 6.2 榜单与口碑

- **AA（2026-11-03）**：开放权重最佳为 H3（T2V 1160 / I2V 1131 / 编辑 1123）与 Hyperflow H3（I2V 1124 / 编辑 1151）；其次是 MAGI-2（T2V 1041）与 LTX-2.5（T2V 940–944 / I2V 913–917）；LTX-2.3（T2V 839–884）、Boreal（T2V 830）在开放权重中偏低[27][28][29]。
- **VBench / VBench-2.0**：VBench 总分开源第一为 Wan 2.2 约 84.7%、Wan 2.1 约 83.1%（第三方汇总，2026-04 口径）[31]；HunyuanVideo 1.5 分项为视觉质量 96.4%、文本对齐 68.5%（厂商/汇总口径）[31]。VBench-2.0（2025 年提出、2026 年进入讨论）转向"内在忠实度"（物理、常识、人体），论文初始评测中头部模型动作忠实度仅约 50%[31]，说明**物理一致性是 2027 年的主要竞争维度**。

### 6.3 开源 vs 闭源差距：三条可写进结论的判断

1. **画质差距已压缩到"可忽略"级别**：含音频 T2V 榜开放权重第一（H3 1160）与榜首（Wan 3.0 1172）仅差 12 Elo；无音频 T2V 差 23 Elo；I2V 差 26/36 Elo。按"20–30 Elo≈53% 胜率"换算，闭源前沿对开源最强只有约 52%–56% 的偏好胜率——**在盲测层面已很难稳定区分**。
2. **差距转移到"许可 + 门槛 + 稳定性"**：闭源最强（Wan 3.0 / Seedance 2.5 / Utopai X）可以无条件商用、按 API 弹性扩容；开源最强（H3）有区域排除，许可最干净的开源（MAGI-2）要 8×H100，能在 24GB 卡上跑的开源（LTX-2.5 Fast、Wan 2.2 5B）落后前沿 200+ Elo。**"开源追上了画质，没追上可商用性与低门槛"是 2026 年 11 月的准确判断。**
3. **开源正在反向输出闭源产品**：MiniMax H3 开权重后，fal 训练出闭源 H3 Max、Pika 做出 H3 Flex、NVIDIA/MIT 做 2K/4K 重生成、社区做 Hyperflow 蒸馏[14][15][16]——**"开放权重成为商业模型的底座与获客入口"** 是 2026 年新出现的产业结构，也是 C 端视频工具成本快速下降的原因之一（H3 API $4.80/分钟 vs Wan 3.0 $12/分钟、Seedance 2.5 $34.12/分钟）[27]。
