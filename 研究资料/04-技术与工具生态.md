## 0 摘要与关键结论

1. **架构主线已收敛为"高压缩视频 VAE/tokenizer + DiT/Omni-Transformer"**。2026年旗舰模型几乎全部采用 DiT 系列架构：Wan2.2（总参 27B、MoE 高噪/低噪双专家、每步激活约 14B）、HunyuanVideo 1.5（8.3B）、LTX-2（14B 视频流 + 5B 音频流的非对称双流）、MiniMax H3（33B 稠密单流 Omni-Transformer）均属此类 `[官方][论文]`。UNet 时代（约2022—2024）已基本结束。

## A 技术篇

### A1 架构演进：VAE+UNet → DiT，以及视频 VAE/tokenizer

**原理与要解决的问题。** 潜在扩散（Latent Diffusion）先用自编码器把像素压到低维 latent，再在 latent 空间做扩散；早期视频生成沿用"3D VAE + UNet"（AnimateDiff、SVD 时代），UNet 的卷积归纳偏置在小分辨率图像上高效，但**视频 token 数随时长线性甚至二次增长**，UNet 难以吃下长序列，也无法享受 Transformer 的 scaling law。DiT（Diffusion Transformer）用 patchify 后的时空 token 直接喂 Transformer，配合 adaLN 条件注入，使"参数—数据—质量"可预测扩展，成为2025—2026年的事实标准。代价是注意力复杂度高，因此需要**更高压缩率的视频 tokenizer + 高效注意力（3D全注意力/分解注意力/窗口/线性注意力/稀疏注意力）**共同支撑。

**视频 VAE 对比（2026年主流）**：

| 模型/VAE | 时间压缩 | 空间压缩 | latent 通道 | 关键特点 | 证据 |
|---|---|---|---|---|---|
| HunyuanVideo VAE | 4× | 8× | 16 | 因果3D VAE，720p/129帧 | `[官方]` Comfy 模型文档 |
| Wan2.1-VAE | 4× | 8× | 16 | 因果3D卷积 | `[论文/官方]` |
| Wan2.2-VAE | 4× | 16× | 48 | 高压缩，支撑 TI2V-5B 高效部署 | `[官方]` Replicate 模型卡 |
| MiniMax H3-VisualVAE | 4× | 16×（patchify后等效32×） | 24 | 时间因果；f16t4d24 | `[官方]` MiniMax H3 说明 |
| LTX-2 | 视频流+音频流分离 | — | — | 14B视频流 + 5B音频流，双向AV交叉注意力 | `[论文]` arXiv 2601.03233 |

**代表模型与成熟度。** Wan2.2 采用 MoE（高噪专家负责整体布局、低噪专家负责细节），总参27B、每步激活14B，官方称同参数规模下节省约50%算力 `[官方]`；HunyuanVideo 1.5 走轻量路线（8.3B DiT，5—10秒高清，2025-11-21）`[媒体]`；LTX-2 用"非对称双流"把视频容量做大于音频容量，并以跨模态 AdaLN 共享时间步、modality-CFG 提升音画对齐 `[论文]`。**成熟度：架构层已成熟并商品化；瓶颈转移到数据质量、长序列注意力与推理成本。**

### A2 自回归视频生成与 Diffusion Forcing / 因果流式

**原理。** 双向扩散必须一次生成整段（或分窗重叠拼接），天然不适合"边生成边播放、可交互、无限长"。自回归（AR）路线把视频切成 chunk/帧，按时间顺序逐块去噪，前块作为后块条件，可配合 KV cache 实现流式输出。核心难题是**训练-推理不一致（exposure bias）**：训练时喂真值，推理时喂自己生成的（有瑕疵的）历史。**Diffusion Forcing** 给每帧/每块独立噪声水平并自回归训练，使模型学会在"不同程度的历史瑕疵"下继续生成，是当前主流解法。

| 方案 | 机制要点 | 能力/数据 | 局限 |
|---|---|---|---|
| SkyReels-V2 | Diffusion Forcing 框架，14B，540P；官方称"无限长度电影生成模型" | 可续写长视频；14B/540P 峰值显存约43.4GB | 显存门槛高，画质随长度衰减 |
| MAGI-1 | 按 chunk（每块24帧）自回归 + block-causal attention + 并行注意力块 + Sandwich 归一化；24B 需8×H100，4.5B 目标单卡4090 | 可流式、可逐块控制 | 生态与工具链弱于 Wan 系 |
| Self-Forcing | 训练时用 KV cache 做自回归 rollout，弥合训练-测试差距，再用 DMD 蒸馏 | 单卡亚秒级流式（NeurIPS 2025） | 论文指出其 ODE 初始化存在理论缺陷 |
| Causal Forcing | 用"自回归教师"做 ODE 初始化，再套用非对称 DMD；动态度+19.3%、VisionReward+8.7%、指令遵循+16.7%（对比 Self-Forcing） | 高质量实时交互视频 | 2026年新方法，第三方复现少 |

**成熟度判断**：AR+因果流式是"实时交互/世界模型"的必经之路，2026年已从论文进入产品雏形（PixVerse R1、Decart Lucy、Genie 4 的实时交互都依赖此类思路），但**长时一致性、错误累积、音画同步**仍是硬骨头。

### A3 少步蒸馏与实时生成

**原理。** 扩散模型推理需几十步；蒸馏把多步教师压到1—4步。主流方法：
- **DMD/DMD2（Distribution Matching Distillation）**：让学生分布匹配教师分布，DMD2 加入多步细化与 GAN 损失，是视频少步蒸馏的事实基线 `[论文]`。
- **CausVid**：从双向多步教师蒸馏出4步因果学生，先做 ODE 轨迹初始化再非对称 DMD，抑制误差累积。
- **Self-Forcing / Causal Forcing**：DMD + 自回归 rollout，把"流式生成"与"少步"合并。
- **TMD（Transition Matching Distillation，arXiv 2601.09881，2026-01）**：系统改进 DMD2 在视频上的三个关键点，形成 DMD2-v 默认配置 `[论文]`。
- **AAD-1（arXiv 2606.03972，2026-06）**：非对称对抗蒸馏做一步自回归视频生成 `[论文]`。
- **LightX2V**：社区最常用的 Wan 系4步蒸馏权重提供方，Wan2.2 蒸馏模型约28.6GB（BF16）；LightWan2.2-A14B 支持"2步高噪 + 2步低噪"专家调度，单张 Blackwell 卡即可跑 `[官方/社区]`。
- **开源蒸馏生态外溢**：MiniMax H3 开源后出现 Hyperflow H3 少步蒸馏版（int8、ComfyUI 节点），在 AA 图生视频（无音频）榜居开放权重第一（团队核实，⚠️待独立复现）`[媒体]`。
- **工程加速三件套**：缓存复用（TeaCache/MagCache/EasyCache）、量化（FP8/GGUF）、并行（xDiT 的 USP/PipeFusion/CFG parallel）。

**实时性数据点（均为官方/媒体口径）**：Self-Forcing 单卡亚秒级；Meta Muse Realtime Avatar 448×768@25fps、首包延迟约870ms（2026-09）；Decart Lucy 2.5 实时30FPS视频变换（2026-07）；PixVerse R1 宣称1080p"即时响应"（2026-01）。**成熟度：4步蒸馏已在消费级广泛可用（Wan2.2+LightX2V 是C端标配组合），1步/实时交互仍在快速演进。**

### A6 统一多模态模型与 Agent 化视频制作

**统一多模态模型。** Gemini Omni（Google I/O 2026，2026-05-19/20 发布）被定义为"可从任意输入创建内容"的模型，首发的 Gemini Omni Flash 单次生成≤10秒，官方叙事是"视频版 Nano Banana"、更偏"调度/编排引擎"而非单纯像素生成器；同期 Google Flow 上线覆盖创作各环节的 agent 与精确视频编辑模型 `[官方][媒体]`。Gemini 4 Argon（2026-10-12）提供100万统一输入输出 token、强化 agentic 能力 `[官方]`。GPT-6 Astra（2026-09-28 起逐步开放）定位通用智能体，可操作 Blender/Unreal Engine、在视频创作中承担"导演+制片"，媒体展示了其端到端产出的成片 `[官方][媒体]`。MiniMax H3 则以"理解文本/图像/视频/音频的统一上下文 + 生成音视频"实现全模态闭环，但其 H3-Context-IR 预处理模块并未开源 `[官方]`。

**"Vibe Video"范式（Claude Opus 5.5）技术含义。** 据界面/钛媒体等报道（2026-10）：Opus 5.5 不直接生成像素，而是通过写代码（前端动画框架 Remotion）、调用工具、找素材、生成/拼接配音与动画来"编程式"产出视频——有创作者用约7400行前端代码在1小时内产出3分钟AI发展史视频；推理初创 Deedy 用其做产品发布视频，生成约1分钟、API 成本约2美元、获32万播放；GitHub `awesome-opus5-5-videos` 合集经多版本增长，2026-10 已称收录2000+作品/700+提示词（Lead 提到的"400+"为其早期规模）`[媒体/社区]`。fal.ai 的实测教程给出同类流程标准价约2.05—2.17美元（不含重试）`[媒体]`。
**技术含义**：①**可编辑性**从"重生成"变为"改代码/改参数"，边际修改成本极低；②**确定性**：版式、文字、品牌色、时长精确可控，适合宣传片/信息图/数据动画，但真实人物与实拍质感仍弱；③**Agent 化生产链**：脚本→资产→渲染→配音→合成可由一个通用 Agent 串起，专业视频模型的护城河从"像素质量"部分转向"素材真实性+一致性+工作流集成"；④成本结构剧变：2美元/条对传统SaaS是降维打击，但只覆盖"图形/动效/解说"类内容 `[推测]`。

### A7 后训练、数据管线与评测

- **偏好优化/RLHF**：VideoReward（NeurIPS 2025）构建多维视频奖励模型，配套 Flow-DPO 显著优于 Flow-RWR 与 SFT `[论文]`；GRPO 类方法进入视频：TAGRPO（ICML 2026）把 GRPO 损失作用于中间 latent，做"高奖励轨迹拉近、低奖励轨迹推远"的直接轨迹对齐，用于图生视频 `[论文]`；DanceGRPO 等2025年工作已把 GRPO 用于视觉生成。
- **数据管线与自动标注**：切片（PySceneDetect/scenedataset）→ 打标（WD14/PixAI/CL ONNX，BooruDatasetTagManagerPlus 支持 WD14 自动打标+LLM captioning+视频抽帧）→ 字幕/描述（Qwen2.5-VL-7B、Qwen3-VL-235B；NVIDIA NeMo Curator 的 video captioning 管线）→ 清洗/去重。学术侧2026年出现大量"LLM驱动半自动视频标注/密集字幕"论文 `[论文/社区]`。
- **物理与常识一致性**：Seedance 2.0 官方称在人物动作、复杂交互上显著改善物理合理性（双人花滑、晒衣等样例）；Genie 4 把物理模拟列为重点改进项；VBench-2.0 专门设 Physics/Commonsense 维度 `[官方][论文]`。
- **评测基准**：VBench（CVPR 2024）测"表层保真"；VBench-2.0（arXiv 2503.21755）转向"内在忠实度"，设 Human Fidelity、Controllability、Creativity、Physics、Commonsense 五维。Artificial Analysis 于2026-09把 AA-Video 重构为 v2.0/v2.1：按1080p统一回放、1000条带"用例/能力/风格"标签的提示词、6.8万+盲测投票，拆分为 T2V（含音频）/T2V-Silent/I2V（含音频）/I2V-Silent 及视频编辑榜，Elo 以 Kling 3.0 1080p Pro=1000 为锚点；**不同版本/锚点的 Elo 不可直接比较**（2026-04 的 HappyHorse-1.0 与 2026-11 的 Wan 3.0 属不同标尺）`[官方榜单]`。

### A8 世界模型、长视频/多镜头、4K 与超分

**世界模型**：Genie 3（2025-08-04）是首个可实时交互的世界模型（限量研究预览）；Genie 4（2026-10-27 研究预览）把场景一致性时长延长到约2分钟（Genie 3 的2倍），改进物理/人物动作并原生生成音频，支持自然语言实时改天气/视角/增删物体，并与 Gemini 4 Argon 协同做机器人任务模拟；官方承认长时模拟仍会细节漂移、音频准确性与文字清晰度待改进，计划通过 Project Genie 向 Google AI Ultra 订阅者开放 `[官方][媒体]`。Marble（World Labs，2025-11-12 商用）从单图/视频/文本生成可持久探索与编辑的3D世界，采用免费增值+订阅，Marble 1.1 推荐使用、单次生成1500基础+0—1500可变积分 `[官方]`；2026-09-28 AMD 宣布以约82亿美元全股票收购 World Labs（媒体口径，⚠️交易状态待核实）。Runway GWM Worlds 2（2026-09-02）为自回归扩散视频+音频模型（720p@24fps、48kHz音频）；国内 PixVerse R1（2026-01-14）主打1080p实时交互；蚂蚁 LingBot-World 2.0（2026-07-09 开源14B，后续1.3B单卡实时版）`[官方][媒体]`。

**长视频与多镜头一致性**：Seedance 2.0 支持15秒多镜头；Wan3.0 原生30秒；学术方案 FilmWeaver（AAAI 2026，缓存引导自回归扩散）与 HoloCine（CVPR 2026，整体生成多镜头叙事）给出全局一致性路径；工程侧 WanVideoWrapper 提供 context window / Diffusion Forcing sampler / StoryMem 等长视频节点 `[官方][论文]`。**判断：10—30秒内"多镜头+音画+主体一致"已可用；分钟级叙事仍需分段+人审。**

**4K/HFR 与超分**：LTX-2 宣称原生4K音视频且权重开放；Kling O3 4K（2026-09）支持4K视频编辑/参考且定价 $0.462/秒（WaveSpeed）；学术侧 ApertureAttn（NeurIPS 2026，仅用单帧高清图监督实现原生4K）、UltraGen（AAAI 2026，层级注意力高分辨率）代表降本路线；主流产品仍以1080p为交付标准。超分：SeedVR2（arXiv 2506.05301，一步扩散对抗后训练，3B由7B蒸馏而来，ComfyUI 已有节点）与 FlashVSR（CVPR 2026，单A100 768×1408 达17FPS，较此前一步扩散VSR最高约12倍加速）代表2026年SOTA；Real-ESRGAN 仍是最通用的低成本基线；补帧用 RIFE/FILM（ComfyUI 0.26+ 已内置 RIFE/FILM 节点，无需第三方插件）`[论文][官方]`。

## C 三条C端工作流方案与成本对比（60秒AI短视频）

以"脚本→分镜→生成→配音→口型→超分→剪辑"为标准链路，60秒成片按约12—20个镜头（每镜3—5秒）估算；成本含重试系数（按2倍生成量计）。

### 方案一：零成本开源本地（已有 RTX 4090/32GB 级设备）

- **工具组合**：LLM（本地/免费额度）写脚本分镜 → ComfyUI + Wan2.2-TI2V-5B 或 LTX-2 量化 + LightX2V 4步LoRA 出片 → Wan2.2-S2V / LatentSync 对口型（如为口播） → SeedVR2/Real-ESRGAN 超分 → RIFE 补帧 → 剪映免费版剪辑配字幕；配音用剪映/必剪免费AI音色或本地TTS。
- **耗时**：熟练者6—12小时（含调试、重抽、手工修），首次上手需2—3天学习。
- **成本**：电费+折旧约¥5—20/条；设备投入另计（4090整机约¥2万+，按3年折旧约¥20/天）。
- **质量/上限**：720p—1080p，画面质感与一致性弱于闭源旗舰，适合个人IP、知识口播、风格化短片。
- **适合人群**：有硬件、愿意折腾、追求零边际成本的创作者。

### 方案二：低成本云API（无高端硬件）

- **工具组合**：豆包/DeepSeek 写脚本 → 即梦/ LiblibAI（Seedance 2.0 mini 720p 约¥0.5/秒）或可灵/海螺出片 → MiniMax/ElevenLabs/剪映配音 → 剪映数字人或 Hedra 口型 → 视频增强软件/SeedVR2（云）超分 → 剪映剪辑。
- **测算**：60秒×2倍重试≈120秒素材，按¥0.3—1.2/秒计约¥36—144；配音约¥10—40；口型约¥20—60；剪辑0（自剪）；合计约**¥70—250/条**（不含会员）。
- **耗时**：2—5小时。
- **质量/上限**：可达商业短视频及格线以上，多镜头一致性依赖模型能力与人审。
- **适合人群**：中小团队、自由职业者、批量做号。

### 方案三：专业闭源SaaS（交付级）

- **工具组合**：Claude Opus 5.5/GPT-6 Astra/Gemini 做脚本+分镜+动效代码 → 可灵3.0 Omni / Seedance 2.0 / Runway Gen-4 出主镜头 → Runway Aleph 2.0 做局部编辑与多镜头统一 → ElevenLabs 配音+音效 → HeyGen/Hedra 数字人 → 视频增强软件超分补帧 → DaVinci/剪映终剪。
- **测算**：主镜头按 Seedance 2.0（第三方平台约$0.12/秒；按 AA 官方 API 口径折算约$0.37/秒，价差约3倍）或可灵3.0 Omni（5秒1080p带音频约$0.70/条）计：60秒×2倍重试≈$14—90；编辑（Aleph）约$10—30；配音音效$5—20；数字人$5—20；订阅摊销$20—80；合计约**$50—220/条**。
- **耗时**：1—3小时（熟练者）。
- **质量/上限**：接近广告/短剧交付级，可控性最高。
- **适合人群**：品牌方、MCN、影视/广告外包团队。

## D 技术趋势判断（2026Q4—2027）

1. **"视频模型"终结，"视听模型"成为默认形态**：原生音频、双声道、多轨、口型同步将从卖点变为基线；后处理拟音（Foley/V2A）会退居"老片修复/补音"场景。
2. **实时化是下一场军备竞赛**：少步蒸馏+因果流式+世界模型三条线在2026年合流；亚秒级延迟、可交互改场景会成为C端产品（直播、互动短剧、教育）的核心指标。
3. **Agent 化重写生产链**：从"提示词抽卡"到"规划—生成—编辑—校验"闭环；通用Agent（Claude Opus 5.5、GPT-6 Astra、Gemini 4 Argon）与垂类视频模型会形成"上层编排+下层生成"的分工，可编辑性和边际修改成本成为选型第一指标。
4. **长视频靠"模型内多镜头+人审分段"推进**：15—30秒原生多镜头已落地，分钟级叙事仍需分段生成+一致性锚点（角色库、场景库、声音库）；世界模型提供"持久场景"作为一致性基础设施。
5. **开源与闭源的时间差缩短到约3—6个月**：LTX-2、MiniMax H3、Wan3.0（未开源）形成"开源可用、闭源领先"的稳定结构；消费级硬件因蒸馏/量化可跑旗舰上一代。
6. **成本曲线分化**：生成成本快速下降，但**算力现货价格上涨**（GPU显存短缺）与**人工审片成本刚性**会吞噬部分红利；"按秒计费+失败不计费"成为主流计费方式。
7. **评测必须内化**：公开榜单覆盖滞后（Seedance 2.5 未被AA/VBench收录），团队应建立"任务成功率+人评+单条成本"的内部基准，而非依赖单一 Elo。
8. **合规与真实性成为产品能力**：真人主体参考需授权（Seedance 官方已声明）、深度伪造检测、内容水印/C2PA 会从"合规成本"变成"平台准入门槛"`[推测]`。
