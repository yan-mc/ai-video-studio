## 一句话定位

**AIGC 视觉内容创作平台**。七条产线装进一张画布，从剧本到成片不出画布。

---

## 整体形态

```
┌─────────────────────────────────────────────────────┐
│  顶栏                                                │
│  [画布] [素材库] [剧本] [导演台×6] [剪辑] [Agent]     │
├─────────────────────────────────────────────────────┤
│                                                      │
│         无限画布（节点式工作流）                       │
│                                                      │
│   节点A ──→ 节点B ──→ 节点C                          │
│                                                      │
├─────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────┘

**桌面端**：Tauri 应用（主程序 115 MB），本地 SQLite（`projects.db`，WAL 模式）存项目。
数据目录：`%APPDATA%\com.luoshu.copilot\`

## 七条产线

| 产线 | 输入 → 输出 |
|---|---|
| **AI 短剧** | 竖屏/横屏量产，镜头级审查、素材跨集复用 |
| **AI 漫剧** | 小说/剧本进，分镜、角色、成片出 |
| **AI 漫画** | 条漫/页漫：线稿→上色→质检→拼版，导出 PNG/PDF/CBZ |
| **AI 有声书** | 小说进，多角色配音成品出（分角色、逐句、情绪标注） |
| **AI 音乐** | 背景音乐与完整歌曲，30 秒起最长 6 分钟 |
| **AI 配音** | 文本到人声，142 个音色，1~4 路同时合成 |
| **AI 电商素材** | 商品图 → 服装/饰品/武器库 → 抠图/扩图/高清 → 带货短片 |

## 核心模块

### 1. 画布与节点

- **26 种节点**：19 类可自由创建 + 7 类流程自动产生
- 建节点：右键菜单 / 端口拉线
- 多选（框选）、Alt 拖拽复制、剪贴板图片直接粘贴成节点
- 撤销/重做 **12 步**
- 三种连线路由：曲线 / 直角 / 智能避让
- 分组容器（折叠/整体移动/解散）、迷你地图、锁定画布
- 剧集画布：一集一个容器，镜头状态可见
- 项目类型：短剧 / 漫剧 / 电商 / 自由创作
- 自动保存（拖拽结束才落盘）

### 2. AI 生成（四条通道）

| 通道 | 节点 | 说明 |
|---|---|---|
| 图像 | AI 图片 | 文生图 / 图生图，参考图接上游 |
| 文本 | AI 文本 | 温度/最大Token/Top-P/模板 |
| 音色 | AI 音色生成、提取音色 | 角色名+音色描述，节点内试听 |
| 视频 | AI 视频 | 参考图/视频/音频，尾帧承接 |

**专用生成节点**：角色提取、场景提取、道具提取、分镜生成、全景生成、背景音乐、智能体生成、姿势台

### 3. 图像工具（14 个）

裁剪、标注、切割分镜、多角度、打光、高清增强、扩图、重绘、擦除、抠图、多功能七合一、编辑面板

**关键设计**：每个工具产物都是**新节点**，原图永不覆盖，可沿另一条路重试。

### 4. 分镜与视频

- 宫格分镜生成（2×2 / 3×3…，每格独立描述）
- 切割拆帧 → 独立镜头节点
- 逐帧备注与拖拽排序
- 视频参数：480p–1080p、4–30 秒、多种比例
- 参考三件套：图 ≤30 / 视频 ≤10 / 音频 ≤10
- **尾帧承接**：上一镜尾帧接下一镜
- 音频开关、音效生成、水印开关

### 5. 素材资产（14 类）

角色 / 场景 / 道具 / 服装 / 饰品 / 武器 / 参考图 / 通用素材 / 视频片段 / 音色 / 分镜 / 控制图 / 动态提示词 / 白模预演

- **变体链**：多版本留痕，一键选定当前形象
- **批量生成**：角色/场景/道具/控制图，进度浮窗实时计数
- **断点续跑**
- 搜索/来源筛选/四种排序/跨页多选
- 一键送画布（自动建节点与连线）

### 6. 剧本创作（5 阶段）

```
大纲 → 人物小传 → 章节目录 → 章节正文 → 视觉分镜
```

- **14 种题材**：玄幻/仙侠/武侠/都市修仙/都市重生/末世/科幻/灵异/宫斗/电竞/娱乐圈/年代重生/机甲/种田
- 章节正文：逐集精修 或 批次模式（一次 5 集）
- 自动一致性检查与修正（上限可调 1~10）
- 前三个阶段完成自动推进
- 产出直接落进当前项目的素材库

## 六个导演台

> 这是最重的一块。顶栏「导演台」开出**六个独立窗口**，可同时开着。

| 导演台 | 定位 | 关键能力 |
|---|---|---|
| **符卡导演台** | 搭 3D 空间、拍镜头 | 两步走（画空间→找镜头）、18 款预制运镜、多轨录制剪辑台、「就这帧」拍进镜头册、一键进故事板 |
| **导演取景器** | 体素风格快速搭景 | 26 种体素组件、4 个预设场景、6 种经典镜头、三种视点、场景 JSON 导入导出、AI 对话搭场景 |
| **3D 导演台** | 掌镜式拍法 | WASD 掌镜连续记轨迹点、双轨时间轴、6 套运镜预设、37 个绑骨人物、Mixamo 动作库、FBX/OBJ/GLB 导入 |
| **AI 导演台** | 工程化三轨时间轴 | **58 个动作模板** + **28 个运镜模板**、24fps 关键帧+贝塞尔、50 步撤销、导出 1080p MP4、**15 个 MCP 工具** |
| **3D 预演导演台** | 全套白模预演 | 11 关节人偶+46 姿势+8 循环动作、**369 个模型素材**、74 个运镜预设、K/J 打关键帧、地形雕刻、OSM 地图 |
| **总导演台** | 整段戏完整预演 | 场景条页签、对象树、6 档景别×6 视点×5 方位×11 运镜、元素时间轴、一句话生成整场、WebCodecs 出 MP4 |

### 白模预演 · 六种看图方式

`play` 导演台视角（可导 MP4）· `grid` 宫格 · `keyframes` 关键帧序列 · `plan` 站位图 · `stage` 场记平面图 · `cut` 接缝检查

三项自检：数据健康 / 越轴 / 接缝角 < 30° 判跳切

| 组件 | 实测结果 |

### 内嵌的子应用（从 exe 提取到的路径）

```
/fuka/                    符卡导演台（主框架）
/fuka/storyboard/         故事板
/previz/                  预演
/director-desk/           导演台（含 local-assets 3D 素材）
/assets/                  Vite 打包产物（166 个文件）

- `guo-mounted-props-200/thumbnails/` — 道具缩略图（桌子、沙发、剑、火把…）
- `guo-scene-presets-200/thumbnails/` — 场景预设
- `guo-skeleton-models/thumbnails/` — 骨架模型（男性/女性/动漫少女…）
- `guo-3d-assets/guo-mounted-props-200/models/*.fbx` — 实际模型文件
