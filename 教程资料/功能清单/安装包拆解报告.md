## 三、主程序 PE 结构

```
洛书灵枢.exe  115.0 MB
节数 6:
  .text   28.8 MB  (代码)
  .rdata  84.4 MB  ★ 前端资源 + 字符串在这里
  .data    0.0 MB
  .pdata   1.3 MB
  .rsrc    0.4 MB
  .reloc   0.1 MB
overlay: 0
```

**关键**：前端资源以**压缩形式**嵌在 `.rdata`（84.4 MB）。

### 压缩格式探测

| 格式 | 结果 |
|---|---|
| zstd 魔数 `28 B5 2F FD` | **0 处** |
| gzip `1F 8B 08` | 7 处（非前端资源） |
| bzip2 `BZh` | 3 处（非前端资源） |
| zlib 流 | 试探 2 MB 窗口，**0 个可解压成 HTML** |

**结论**：Tauri 用了 **brotli**（无魔数），符合 Tauri v2 默认行为。
