## 01 H3 成片工作台

页头链路：**剧本 → 分段 → 出片 → 审片 → 剪辑 → 交付**

### 六步流程

1. **填剧本** — 作品名必填；剧本直接贴，或从「剧本创作」「分镜师 3.0」导入。服务端只拆前 **12000 字**
2. **定参数** — 画幅（16:9 / 9:16 / 1:1）、平台（视频号/抖音/快手/B站/小红书/其他）、目标片长（**15～1800 秒**，默认 180）
3. **规划分段** — 服务端拆成 **4～15 秒**小段，规划每段怎么拍；分段表门禁标出每段缺什么
4. **出片** — 每段至少 1 张参考图（部分模型还要 1 段参考音频），用 **AutoDL 令牌**调 H3
5. **审片** — 候选「选为入片」；单看/左右/闪烁对比，可截帧、听写抽查台词、记反馈
6. **剪辑交付** — 拖时间线改入出点、换序；加房间声/音效/图文卡/调色/配乐；导出成片

### 关键注意点

- **H3 结果地址约 24 小时过期**，出片成功自动转存本地（徽标「已存本地」）；漏转点「转存本地」，过期只能重新生成
- 同一段不能同时出多条
- 预览是分段跳播，配乐/混音/调色**只在导出的成片里生效**
- **门禁是体检不是闸**：未过也能导出，报告写清差多少

## 02 H3 提示词工坊

**核心逻辑**：一集剧本进去，**9 份文档**出来；客户端再把分段表编译成每段一份的镜头提示词，每份带可直接粘贴到 H3 的英文提示词。

### 流程

1. 给剧本（粘贴 或 选 .md/.markdown/.txt）
2. 填参数：集数、画幅、目标时长、台词语言、作品名、平台、画面风格、LLM 模型
3. 「分析这一集」— 显示步骤和百分比；**关掉面板任务也继续跑**，重开自动恢复
4. 看产物：9 份文档 + 每段提示词（`提示词/镜头/S01.md`）
5. 「导入资产库」— 人物/场景/道具→素材库资产，音色→音色资产，镜头→分镜资产；显示「新建 X · 更新 Y · 未变 Z」

### 三个关键设计（对我们最有参考价值）

1. **只分析一集** — 多集要一集一集跑，集数自动 +1
2. **画风由需求单决定** — 面板「画面风格」留空就不注入画风块；需求单里写了项目画风，镜头提示词优先用它
3. **★ 提示词是编译的，不是模型直接写的** — 服务端只出**中性分段数据**，H3 方言的脚手架由客户端代码按**固定规则**拼出来，**同一集重复编译结果一致**

> 这一点直接印证了我们项目里「预演 → 文字描述」的做法是对的。

- 只导提示词、图位和参考顺序，**不生成图**
- 重复导入同一集不会建重卡，按资产身份更新，已生成的图和音频不会被删

## 03 专业剪辑（FilmCraft 集成）

点一下做三件事：
1. 把当前项目的媒体素材同步进一个剪辑工程文件
2. 拉起一个独立的 **FilmCraft 定制版**窗口
3. 直接载入这个工程

工程按项目绑定：一个项目↔一个工程文件↔一份素材。

- 第一次打开会先同步素材
- 下次只同步新增文件（增量导入，秒开）
- 同项目已开着时提示「请从任务栏切换」
- 洛书只在**本次运行期间**记得这个项目已开窗口

## 04 Agent 编排与技能市场

右侧停靠面板，不挡画布。

- 输入框说一句话 → Agent 读作品数据、批量改节点、放图片、生成图/视频、调技能
- 最后用中文回一句「做了什么、结果如何」

### 四道权限（按项目记忆，默认后三项关）

| 权限 | 默认 |
|---|---|
| 允许修改画布 | 开 |
| **允许产生费用** | **关** |
| **允许删除节点** | **关** |
| 自动执行（跳过审批） | **关**（危险） |

- 写操作默认先审批（弹「确认执行」，可「撤销全部」）
- 单次最多 **12 轮**
- 撤销只在本次面板会话内有效

### 技能市场

- 页签「全部」「已启用」，按分类筛选
- 卡片显示技能名、分类、版本、状态徽标
- 详情有「这是什么」「什么时候用」「会产出什么」三块
- 状态：已启用 / 未启用 / 已停用 / 已下架 / 暂不可新装
- 分镜师/漫画/H3 专属工作台的技能**不进市场**
