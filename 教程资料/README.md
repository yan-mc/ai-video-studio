## 三个最有价值的发现

### 1. ⭐ 原版导演台前端可直接运行

拆包得到 `resources/director-web/`（3 个文件 819 KB），是一个完整的 Vue 3 + three.js 应用。
它只依赖 3 个 HTTP 接口，而**我们的预演引擎全都有且格式一致**。

实测：托管后反向代理到 4318 引擎，无头 Edge 打开 → **零错误，UI 完整渲染**。

已落地到 `工作室/studio-apps/director/`，零品牌残留。

### 2. 原版是 Tauri + Vue 3 + Vite

不是 Electron，不是 React。主程序 115 MB 含内嵌前端（brotli 压缩）。

### 3. 提示词是「编译」出来的

v1.0.59 明确写：服务端只出**中性分段数据**，H3 方言的脚手架由客户端按**固定规则**拼出来，
**同一集重复编译结果一致**。

这印证了我们「预演 → 文字描述」的做法是对的，也说明提示词应该做成编译器而不是让模型自由写。
