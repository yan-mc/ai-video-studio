## 从教程提取的关键事实

### 顶栏结构（教程 04）

**无项目时**：左边品牌 + 右边 5 个小图标（余额 / 语言 / 主题 / 检查更新 / 设置）

**进项目后**多出两截：

| 位置 | 内容 |
|---|---|
| 左侧菜单条 | 文件 / 编辑 / 视图 / 节点 / 帮助 |
| 右侧工作入口 | 资产库 / 灵感库 / 剧本创作 / 分镜师工作台 / 漫画工作台 / 导演台 / 配音台 / 技能工坊 |

**文件**：新建项目 / 项目管理
**编辑**：撤销 / 重做（无操作时置灰）
**视图**：适配视图 / 切换主题 / 节点卡片图鉴
**节点**：添加节点（= 画布右键菜单）
**帮助**：检查更新 / 关于

**设置 11 分区**：外观 / AI 默认参数 / 提示词库 / 快捷键 / 使用记录 / 价格说明 / 模型与 API / 即梦 / 授权与换绑 / 更新 / 关于

### 26 种节点（教程 07）

**菜单里七类 + 1 个独立项**：

| 分类 | 节点 |
|---|---|
| 文本 | AI 文本、文本注释 |
| AI 提取 | 提取音色、角色提取、场景提取、道具提取 |
| 图片 | AI 图片、上传图片、分镜生成、全景图A·探索版、全景图B·查看版、姿势台 |
| 智能体 | 三级菜单（智能体→业务线→模板名） |
| 音频 | AI 音色生成、上传音频、背景音乐生成 |
| 视频 | AI 视频 |
| （直接建） | 导演台、全景生成 |

**菜单外的 7 种**（流程自动产出）：

| 节点 | 来源 |
|---|---|
| 上传视频 | 白模底片、资产库「添加到画布」 |
| 结果图片 | AI 图片 / 分镜生成出图后自动落 |
| 结果视频 | AI 视频出片后自动落 |
| 分组 | 框选后 Ctrl+G |
| 切割结果 | 图片跑完「切割」工具后 |
| 剧集画布 | 剧集/剧本导入时 |
| 白模预演 | 资产库「添加到画布」（需镜头表） |

### 六个导演台（教程 16）

| # | 名称 | 形态 | 核心能力 |
|---|---|---|---|
| ① | **导演取景器** | 三栏：AI Director / 3D 视口 / Scene Tools | 预设场景卡（围桌访谈等，免费用）、经典镜头一键录制、一键截图 |
| ② | **3D 导演台** | 独立窗口 | UE4 人偶（20 姿势 + 6 动作）、六类道具库、纯离线、当前视角/四方位/十二方位截图 |
| ③ | **AI 导演台（白模预演）** | 左分镜 / 中舞台 / 右三页签 / 底时间轴 | 58 动作模板 + 28 运镜模板、导演助手（自然语言） |
| ④ | **3D 预演导演台** | 独立窗口 | 手机虚拟摄像机、真人走位、本地桥 + 二维码 |
| ⑤ | **符卡导演台** | 两页互通 | 01 画空间（2D 平面）→ 02 找镜头（立起来）；「就这帧」→ 镜头册 → 「去往故事板」 |
| ⑥ | **总导演台** | 独立窗口 | 片场名/场次条/对象树/三段时间轴、一句话 AI 生成整场、WebCodecs 出 MP4 |

**共同规则**：
- 截图/录屏 → 素材库「参考图」和「视频片段」，名字带时间
- 同一个台只有一个窗口（已打开则聚焦）
- AI 功能走账户额度，其余本地免费
- 数据在本机，换电脑不带走，重要场景要导 JSON
