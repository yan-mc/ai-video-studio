教程 19｜模特工作台：电商素材怎么出
电商素材那条线，一句话就能说完：先造一张脸，再排一单活。 这一篇就按这个顺序走——形
象库定妆锁定，然后新建一单电商拍摄。
0 1 / T U TO R I A L
进门：左栏「模特工作台」
画布左栏点「🧍 模特工作台 →」进入。左边三个页签：
2026年10月18日 11:21 云南洛书智创

<!-- page 2 -->
·作业：每一单拍摄都在这（空的时候会告诉你"拍一件衣服的正面、背面、细节，丢进来，选个风
格，剩下交给它"）；
·形象库：这个项目的演员表；
·方案库：把常用设置存成方案，下次一键套用。
页面上还写着一条让人安心的规矩：历史永久留在本机 · 由你手动删。
0 2 / T U TO R I A L
第一步：先有脸（形象库）
形象库的定位很明确：本剧组的演员表 · 定妆锁定后跨镜头、跨集都是这张脸。
已有几个形象（示例里是知情者、叶昭、阿岩），都标着「未锁定身份」。中间这张是新角色「虚拟
角色 1017-2359」，挂着两张定妆候选——每张上面一颗「用这张」，下面还有「整张重出」。
0 3 / T U TO R I A L
建形象：属性表填完，出两张候选

<!-- page 3 -->
点右上「建形象」打开属性表：
·人物 / 神兽二选一；
·性别、年龄段（儿童 3~6 到 50+）、地区人种（东亚 / 东南亚 / 南亚 / 中东 / 欧洲白人 / 非裔 /
拉丁裔 / 混血）；
·身高体重、体型（纤瘦 / 标准 / 健美 / 微胖 / 大码）；
·肤色、气质（自然 / 清纯 / 甜美 / 干练 / 高级冷感 / 阳光 / 成熟 / 街头 / 运动）；
·发型：长度、卷直、刘海、发色、妆容。
顶部那行小字会实时汇总你的选择（示例： 女 · 26~35 · 东亚 · 自然 ）。填完点「生成 2 张定妆候
选」——本示例实测 86 秒出 2 张，一张一毛，两张 ¥0.2。
0 4 / T U TO R I A L
第二步：挑一张，锁定身份

<!-- page 4 -->
两张候选里点「用这张」，这张脸就锁定了：卡片上变成「已锁定」「虚拟形象 · 已锁定」。以后这
个角色跨镜头、跨集都是这张脸——这就是模特工作台最核心的一件事。
不满意可以「整张重出」（重新花钱出两张），或者删掉重来。
0 5 / T U TO R I A L
第三步：新建作业（电商拍摄）
回到「作业」页签，点「新建作业」，两种拍法：
·电商拍摄：一件衣服进，一套商品图出；
·影视角色：一个角色的整套形象图（定妆 → 三视图 → 表情/姿态）。
电商拍摄这一页从上到下四块：

<!-- page 5 -->
1. 服装素材 · 一套 1-6 件：正面必传；第一件默认为主品（要卖的那件），可改；每件 1-3 张。
「加一件（包 / 配饰）」可以从服装库选，也可以现场传；
2. 模特（必选）：从形象库选（未锁定身份的角色不可用），或者「生成虚拟模特」现场造一个；
3. 拍摄设置：风格 6 个预设（国内棚拍白底 / 国内街拍生活感 / 日系 / 韩系 / 欧美独立站编辑风 /
亚马逊白底主图），也可以一句话自定义；尺寸整组统一（示例 3:4 · 2K）；张数 4 / 8 / 12；
4. 镜头清单 · 8 张：主图、佩戴特写、细节、半身、生活动势、多角度、情绪、备选主图——每一
行都能单独「改」，提交前逐镜头调。
右下角是这一单的报价：预计 8 张 · 2K · ¥0.80，下面一行小字：提交后先出主图，过检后并行出
其余 7 张。影视角色那边是 13 张 · 9:16 · ¥1.30。
点「开始生成」之前，先看这个预计价——这是这套工作台里唯一一处把价格直接摆在你面前的地
方。
0 6 / T U TO R I A L
方案库：常拍的活儿存下来
拍法固定（比如"国内棚拍白底 + 8 张 + 某模特"）就存成方案：方案库支持一键套用、改名、删
除；下一次新建作业，顶部「套用方案」直接带出全套设置。
0 7 / T U TO R I A L
花费与耗时（本示例实测）
动作 花了多少 耗时
生成 2 张定妆候选 ¥0.2 约 86 秒
一单 8 张电商图（只报价，未提交） ¥0.80 —
影视角色整套 13 张（只报价，未提交） ¥1.30 —
记住：定妆先出 2 张让你挑，挑中再花后面的钱——脸不锁定，后面的活别急着开。
