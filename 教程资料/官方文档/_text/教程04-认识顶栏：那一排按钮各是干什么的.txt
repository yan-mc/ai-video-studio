教程 04｜认识顶栏：那一排按钮各是干什么的
顶栏上那堆图标，最容易让人发懵的是：它会长会短 —— 没打开项目时是一小条，进了项目
才长出菜单和一排入口。这篇一次认全。
0 1 / T U TO R I A L
先说个容易懵的事：顶栏会变
这是项目管理页的顶栏——很短：左边品牌，右边五个小图标，就这些。
点「教程演示」进去。再看一眼顶栏：
2026年10月18日 11:16 云南洛书智创

<!-- page 2 -->
长出来两截：
·左边多了一整条菜单：文件 / 编辑 / 视图 / 节点 / 帮助
·右边多了一排干活的入口：资产库 / 灵感库 / 剧本创作 / 分镜师工作台 / 漫画工作台 /
导演台 / 配音台 / 技能工坊
记住这一条就够了：菜单条是"项目里才有"的 —— 因为它管的是"当前这个项目"的事。
0 2 / T U TO R I A L
五个菜单，挨个点开看看
文件 —— 管的是项目本身（新建项目 / 项目管理）：
编辑 —— 撤销 / 重做（没东西可撤销时会置灰）：

<!-- page 3 -->
视图 —— 适配视图、切换主题、节点卡片图鉴：
节点 —— 「添加节点」，就是画布上右键那个菜单：
帮助 —— 检查更新、关于洛书：

<!-- page 4 -->
关掉菜单很简单：点顶栏空白处就收起来了，不会误触任何东西。
0 3 / T U TO R I A L
右边那五个小图标
从左往右：余额、切换语言、切换主题、检查更新、设置。
点「设置」看一眼里面是什么样（看完点取消，什么都不用改）：

<!-- page 5 -->
设置里有十一个分区：外观 / AI 默认参数 / 提示词库 / 快捷键 / 使用记录 / 价格说明 /
模型与 API / 即梦 / 授权与换绑 / 更新 / 关于 —— 后面有专篇讲。
0 4 / T U TO R I A L
最右那一排：干活的入口
八个，从左往右：
入口 干什么
资产库 开关素材库侧栏（角色的立绘、场景图都在这儿）
灵感库 示例库 / 提示词库两个页签
剧本创作 开关剧本创作侧栏
分镜师工作台 分镜视频流水线（全屏面板）

<!-- page 6 -->
入口 干什么
漫画工作台 漫画制作流水线
导演台 六张卡，六种摆镜头的方式
配音台 独立窗口，专门配人声
技能工坊 技能工坊面板
试一个最轻的——「资产库」是开关，点一下滑出来、再点一下收回去：
后面四个（分镜师 / 漫画工作台 / 导演台 / 配音台）会占满屏或另开窗口，各有专篇，
这里只要认得它们在哪个位置就行。
0 5 / T U TO R I A L
退回去，顶栏又变短了

<!-- page 7 -->
点左上角返回——菜单条又没了。这不是 bug，是设计：菜单管的是"当前项目"，没有
项目自然就没有。
一句话记住顶栏：左边菜单（有项目才有）、中间那排小图标（全局设置）、最右一排
（干活入口）。
下一篇，认认主界面那三块：画布、素材库、模特工作台。
