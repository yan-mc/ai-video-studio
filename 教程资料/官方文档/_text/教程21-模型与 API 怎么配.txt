镜像卡的地址有两个要点：填到端口就行（https://uXXXXXX-xxxx.bjb2.seetacloud.com:8443，系统自
动补 /newapi）；地址一改即失效——哪怕改一个字符，状态会回「地址已修改，请重新测试」，镜
像模型也跟着从模型选择器里消失。
地址框空着点「测试连接」，会就地红字提示「请先填写镜像地址」；填好再点，状态走：未测试
→ 检查中… → 已连通（或未连通 + 红字原因）。连通后镜像模型才会出现在「AI 图片」「AI 视
频」和编辑模式三个入口里。
0 3 / T U TO R I A L
脚本创作服务卡

<!-- page 3 -->
列表最底部、金色描边的「脚本创作服务」只有一样东西：文本模型下拉。进页面自动拉清单，选一
个就行——它服务的是顶栏「剧本创作」，没有第二个保存按钮（统一走设置底部的「保存设
置」）。
0 4 / T U TO R I A L
即梦：设备码连接，没有 Key
即梦是另一套：不用 API Key，走官方设备码授权（截图里的账号信息已打码）。点「连接即梦」
→ 下载组件 → 软件拉起浏览器授权页 → 输入面板上的授权码 → 已连接。内测期仅限会员账号；费
用走你自己的即梦积分，提交前会弹「这次提交要花即梦积分」让你批准。
0 5 / T U TO R I A L
两个最要紧的

<!-- page 4 -->
1.填了 Key 必须点设置底部的「保存设置」。卡片上的「已配置」Chip 是一输入就翻的（读的是本
页编辑态），但 Key 真正写进软件存储要等你按保存——填了直接关窗等于白填。
2.不配任何第三方也能干活：洛书账户自带 Nano Banana / GPT Image 出图、Seedance 视频、
AI 文本、音色提取、分镜/漫画/模特等全部自营生成——登录 + 激活授权 + 有余额就行。第三
方配置是"想用自己的账号"时才需要。
没改任何东西就直接「取消」退出——注意它和「保存设置」是两颗按钮，别按错。
