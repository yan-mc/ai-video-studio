# 资产包与挂载规范

> 注：本文件为历史归档，其中的软件名已中性化处理。

> 配套《方案总览.md》。所有资产（模型/3D/动作/道具/schema/模板/音频/字体）全部外置为**可挂载资产包**；插件本身不内嵌资产。
> 本规范定义包结构、manifest schema、挂载 API、校验与"可附带挂载"方式。

## 1. 设计原则

1. **代码与资产分离**：插件仓库只有代码；资产包可独立复制/挂载/卸载/分享（按许可）。
2. **ID 引用**：模块只引用 `packId:entryId`，不写死路径。
3. **可附带挂载**：资产包可放在任意磁盘/NAS；通过 `.dsh-assets.json` 或面板挂载；支持"仅清单引用"（不复制大文件）。
4. **许可可见**：每个包必须有 `license` 字段；UI 显示；禁分发资产标记 `distribution: forbidden`。
5. **缺包可诊断**：任务提交前解析依赖，缺包/版本不符给出明确错误与安装指引。
6. **版本化**：包 `version` + `schemaVersion`；破坏性变更升 major。

## 3. `manifest.json` schema

```json
{
  "schemaVersion": 1,
  "id": "previs-3d-core",
  "name": "预演软件 3D 核心资产包",
  "kind": "3d",
  "version": "1.0.0",
  "license": { "spdx": "NOASSERTION", "distribution": "forbidden", "note": "预演软件内部资产，仅本地自用，禁止分发" },
  "source": { "origin": "预演软件 1.0.19 拆解", "path": "F:\\AI视频\\功能拆解\\预演软件\\04_解包资产", "ref": "1.0.19" },
  "requirements": { "plugin": ">=0.1.0", "schema": ">=1", "diskMB": 260 },
  "tags": ["3d", "scene", "motion", "guo"],
  "entries": [
    {
      "id": "guo.prop.sword-1",
      "type": "model/fbx",
      "path": "guo/props/sword-1.fbx",
      "thumb": "guo/props/sword-1.png",
      "bytes": 123456,
      "sha256": "…",
      "tags": ["prop", "weapon"],
      "deps": [],
      "meta": { "defaultScale": 0.01 }
    }
  ]
}
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `schemaVersion` | ✅ | 清单 schema 版本 |
| `id` | ✅ | 全局唯一包 ID（kebab-case） |
| `kind` | ✅ | `model/3d/motion/schema/template/audio/font/doc` |
| `version` | ✅ | 包版本（semver） |
| `license` | ✅ | `{spdx, distribution: allowed|restricted|forbidden, note}` |
| `source` | ✅ | 来源（origin/path/ref） |
| `requirements` | — | 插件/schema/磁盘/显存要求 |
| `entries[]` | ✅ | 资产条目；`id/type/path/bytes/sha256/tags/deps` |
| `entries[].meta` | — | 类型特有字段（scale/rig/format/clip 等） |

## 4. 挂载接口

```ts
interface AssetPack { manifest: Manifest; root: string; enabled: boolean; }

interface AssetRegistry {
  listPacks(): AssetPack[];
  mount(packId: string, root: string, opts?: { copy?: boolean }): Promise<AssetPack>;
  unmount(packId: string): Promise<void>;
  enable(packId: string, enabled: boolean): Promise<void>;
  verify(packId: string): Promise<VerifyReport>;       // 文件存在 + sha256 + 依赖
  resolve(ref: string): ResolvedAssetRef;              // "packId:entryId"
  find(query: { kind?: string; tags?: string[]; text?: string }): AssetEntry[];
}
```

- `mount` 支持 `copy:false`（仅登记路径，默认）与 `copy:true`（复制到根目录，便于打包）。
- `verify` 输出缺失/多余/哈希不符/许可禁用清单。
- 未挂载包被引用时：报 `ASSET_PACK_NOT_MOUNTED` + 挂载命令/面板入口。

## 5. 各类型包规范

### 5.1 模型包（kind=model）

- 必需条目：`diffusion_model`、`text_encoder`、`vae`（视频/音频）、可选 `lora`。
- `meta`：`format`（safetensors/gguf）、`precision`（fp16/int8/nf4/q4_k_m）、`vramGB`、`profile`（P12/P16/P24）、`backend`（comfyui/sglang/diffsynth）。
- 一个包可含多 profile 文件；适配器按显存选。

### 5.2 3D 包（kind=3d）

- `meta`：`format`（fbx/glb/pma/json）、`rig`（miorning-adult-v1/mixamo/guo）、`animations[]`、`defaultScale`、`thumb`。
- 场景包（pma）：附 `scene-index.json`；转换器可作为可选工具，不强制。

### 5.3 Schema 包（kind=schema）

- 节点动画软件/视频增强软件 JSON 原样放包内；`license.distribution=restricted`；仅在本地开发/自用。
- 使用时只读取字段/枚举，不把原文随插件分发。

### 5.4 模板/音频/字体包

- 模板：提示词/分镜/片头模板 JSON + 变量 schema。
- 音频：`meta` 含 `durationSec/sampleRate/channels/loudness`；人声参考需 `consent` 字段。
- 字体：`meta` 含 `family/license`。

## 6. 可附带挂载方式

1. **工作区挂载文件**：`data/mounts.json` 列包；启动自动挂载。
2. **包内自描述**：`.dsh-asset-pack.json`（与 manifest 同内容）便于分发识别。
3. **面板挂载**：资产页"添加目录→校验→启用"。
4. **任务级挂载**：`studio_generate` 允许 `mountPacks:[...]` 临时挂载（校验后释放）。
5. **只读挂载**：`readonly:true` 防误删/误改。

## 7. 校验与安全

- 启动/挂载时：manifest schema 校验、`sha256` 可选校验、重复 id 检查、许可禁用检查。
- 路径安全：所有 entry 路径解析后必须在包根内（或显式允许的外部引用）。
- 大文件：不复制、不哈希全量（可选抽样）；仅在需要时读。
- 来源台账：每次挂载写 `provenance`（包 ID/来源/许可/挂载时间）。
